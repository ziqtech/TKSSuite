# Note 命令逆向分析

> 数据来源: 运行时转储 反编译源码

## 概述

Note (opcode 46) 是脚本 VM 的标记写入指令，将一个 16-bit 值存入全局数组 `word_7568D8[1000]` 的指定槽位。游戏菜单的 Note 标签页通过按值搜索该数组，找到匹配的 slot 后映射到 TKT 文本显示。

## 核心公式

```
显示文本 ID = slot_index + 11201
```

例: `Note(0, 1)` → slot=0 → 显示 TKT 文本 ID 11201

## 调用链总结

```
脚本 Note(slot, value)
  → VM case 46
    → sub_40DBF4(slot, value)
      → word_7568D8[slot] = value

玩家打开菜单 Note 标签页
  → sub_422158 切换子标签 1/2
    → sub_41A7A8 搜索 word_7568D8 中 value==1 或 2 的 slot
      → 存储匹配的 slot 到结果缓冲区

渲染
  → sub_41A080
    → sub_4067E8(slot + 11201)  // 获取 TKT 文本
      → sub_409C60 格式化
        → sub_44E49C 渲染到屏幕
```

## 扩充 Note 内容

1. **选择未使用的 slot** (0~999)
2. **脚本中调用**: `Note(slot, value)` — value=1 出现在子标签1，value=2 出现在子标签2
3. **TKT 文本中添加**: text ID = `slot + 11201` 的文本条目

### 限制

- 最多 1000 个 slot (0~999)
- 每页最多显示 3 条结果
- text ID 范围: 11201~12199 对应 slot 0~998
- 文本必须存在于 TKT/GXP 资源，否则报错 "Cant find talk num %d!!"
- word_7568D8 不存档，运行时初始为 0
