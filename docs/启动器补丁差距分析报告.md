# 孝谈三国3终极版与启动器补丁体系差距分析（已修正版）

> 2026-09-14 修订。
>
> 早期版本把孝谈版误写成“31/34 个 IAT Hook + 外部辅助程序修改内存数据”。
> 该结论已废止。孝谈版实际是直接修改二进制控制流，重点改动战斗、奖励、脚本、技能和召唤逻辑。

## 一、结论

孝谈版 `TKS.exe` 与当前启动器的关系，不是“外挂程序注入 modifier”，而是：

```text
原版 EXE
  ↓ 静态修改
孝谈版 EXE
  ├─ .text 内 65 个改动区
  ├─ .test 中 30 个 cave 入口
  ├─ .data 召唤表和状态持续值修改
  └─ .Silvana 重建导入表
```

因此启动器需要解决的是：

- 识别孝谈版 profile。
- 避免在已被孝谈版改写的地址上重复写入。
- 对冲突位置跳过、覆盖或使用新的 cave。
- 不再把辅助程序文件缺失视为退出条件。

## 二、孝谈版真实二进制结构

| 节名 | VA | 原始大小 | 用途 |
|---|---:|---:|---|
| `.test` | `0x00A7D000` | 4096 字节 | 主要 cave 和寻路代码 |
| `.Newdata` | `0x00A7E000` | 4096 字节 | 字符串 |
| `.Silvana` | `0x00A7F000` | 354 字节 | 重建导入表 |

新增导入：

```text
kernel32.dll!WinExec
shell32.dll!ShellExecuteA
```

`.text` 共有：

```text
65 个连续改动区
517 个差异字节
25 个差异区以长跳转进入 cave
30 个 cave 入口
```

## 三、与启动器最相关的修改

### 3.1 战斗伤害与行动

孝谈版直接改写了大量战斗公式：

- 多个技能有专属倍率。
- 燃烧和冰冻状态几乎不再扣血/掉内力。
- 防御状态写入错误值，导致魔将发光 BUG。
- 行动值随机区间和灵魂资源增减发生变化。
- 移动范围取消 10 格上限。

启动器中的同类补丁如果继续按原版字节模式盲写，可能会与孝谈版冲突。

### 3.2 经验和掉落

- 战斗经验池上限 `30000 → 59910`。
- 死亡队员也会参与经验/JP结算。
- 第二掉落由 20% 改为必定成功。
- 第三掉落由 5% 改为必定成功。
- 掉落数量超过 99 时改写为 1。

因此：

- 经验倍率类补丁必须避开孝谈版已改写的 `43B7FC` 附近。
- 掉落概率类补丁不能在未校验版本的情况下直接重复写入。

### 3.3 脚本、金钱和判定

- `CheckItem(...,3000,1)` 被追加主角等级 ≥21 限制。
- 金钱 `-30` 被改成 `100 × word_9507EA + 100`。
- 脚本参数 30、50 被替换。
- `CheckAttribute` 类型 14、15 分别追加 40、100。

这些改动会影响剧情、赌场、任务和商店流程。

### 3.4 召唤数据

召唤函数的实际角色索引规则是：

```text
WarPC = 召唤表值 + 36
```

孝谈版修改了：

- 技能 222 的随机目标。
- 技能 229 的召唤目标。
- `.data` 中状态 20-27 的持续值；这部分与技能 200-215 无关。

其中技能 229：

```text
原版：召喚毒蜘蛛 → WarPC 137 毒蜘蛛
MOD ：碧海潮水   → WarPC 67 天師精魄
```

启动器里的 summon 表补丁必须使用“表值 + 36”的规则，不能把表值直接当成 WarPC 编号。

## 四、IAT Hook 结论已废止

早期文档中的错误结论：

```text
.test 是 IAT Hook Thunk
共有 31/34 个 IAT Hook
辅助程序负责修改角色、物品、技能内存
```

这些结论不再使用。

实际事实：

- `.text` 中是直接 `E9` 近跳转到 cave。
- `.test` 是直接执行代码，不是 IAT thunk。
- 检测辅助程序的响应退出代码是不可达死代码。
- 游戏不依赖 `YinShiXing2013.exe`、`system.exe` 或 `closesystem.exe` 才能运行。

## 五、启动器兼容策略

### 5.1 识别

可以通过：

```text
.test
.Newdata
.Silvana
```

三个额外节区识别孝谈版。

### 5.2 应用顺序

| 补丁类型 | 策略 |
|---|---|
| 原版入口补丁 | 先扫描原字节 |
| 孝谈版已有 cave | 明确标记 override 或 skip |
| `.test` 内补丁 | 使用额外节区扫描，不使用常规 `.text` 窗口 |
| 召唤表补丁 | 校验表地址和“表值 + 36”规则 |
| 辅助程序清理 | 可选，不代表可玩性依赖 |

### 5.3 冲突处理

以下区域应重点检查：

- `0x44095A`：技能 133 伤害公式。
- `0x444C9C`：技能 222 随机召唤。
- `0x43E95F`：防御状态错误。
- `0x43B954`、`0x43BAE3`：经验池上限。
- `0x441A25`、`0x441A97`：掉落概率。
- `0x43D0E8`：移动范围。
