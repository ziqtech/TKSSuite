# mat_editor 编辑器规划文档

## 目标

对 TKMat.Dat (实体表, 6000条×384B=2,304,000B) 提供加载/新增/编辑/保存功能。

## 文件格式

> **说明**：本文为 mat_editor **规划/路线图**（设计文档）。所引游戏事实均已核实：TKMat 6000×384=2304000、`sub_452544` 无压缩直读、`type[0]==0` 空记录、TKT 场景名 = `scene_id+300`（见本目录 TKMat 分析 + `../tkt_editor/文本范围分析.md`）。

- **无压缩**原始二进制 (sub_452544 直接 ReadFile)
- 6000 条记录，每条 384 字节 = 96 个 int32 LE
- 空记录: type (索引[0]) == 0

## 核心功能

### 1. 加载
- 加载 TKS 目录 (选择目录, 自动找 TKMat.Dat)
- 可选加载 TKT.dat 获取场景名称 (TKT_ID = scene_id + 300)
- 可选加载 TKDefUnit.dat 获取关联脚本信息
- 解析 6000 条实体记录
- 按 scene_id 分组，统计各类型数量

### 2. 列表视图
- 左侧 TreeView: 索引 | 类型 | 场景 | 坐标(X,Y) | 名称
- 筛选: 按类型、场景、搜索
- 排序: 支持按列排序
- 颜色标记: 不同类型使用不同颜色

### 3. 编辑面板
- 右侧分组编辑:
  - 基础属性: type, scene_id, flags
  - 位置: x, y, bound_x, bound_y
  - 动画: anim_set, direction, dir_mode, sub_model
  - 脚本: cur_define, defunit_idx, max_A/B/C, cur_A/B/C, head_A/B/C
  - 运行时 (只读提示): tick, timer, script_PC, saved_PC, frame_idx, frame_count, frame_cur
- 场景名称显示 (来自 TKT)
- 类型下拉选择

### 4. 新增/复制/清空
- 新增: 在第一个空槽创建, 默认 type=200
- 复制: 复制当前记录到空槽
- 清空: 将当前记录 type 设为 0

### 5. 保存
- 原始二进制写入 (6000 × 384 = 2,304,000 字节)
- 保存前验证文件大小

### 6. 导出
- CSV 导出 (所有字段)
- 可筛选导出

## 字段列表 (编辑器中可编辑的)

### 基础属性组
| key | 索引 | 标签 | 控件 |
|-----|------|------|------|
| type | [0] | 实体类型 | 下拉框 (5/10/15/16/20/110/200) |
| scene_id | [1] | 场景ID | 数值输入 + TKT名称显示 |
| flags | [2] | 标志位 | 数值输入 |
| param | [3] | 扩展参数 | 数值输入 |

### 位置组
| key | 索引 | 标签 | 控件 |
|-----|------|------|------|
| x | [10] | 坐标X | 数值输入 |
| y | [11] | 坐标Y | 数值输入 |
| bound_x | [18] | 碰撞X | 数值输入 |
| bound_y | [19] | 碰撞Y | 数值输入 |
| direction | [13] | 朝向(1-8) | 数值输入 |

### 动画组
| key | 索引 | 标签 | 控件 |
|-----|------|------|------|
| anim_set | [9] | 动画集ID | 数值输入 |
| dir_mode | [53] | 方向模式 | 下拉框 (4=NPC, 8=玩家, 0=静态) |
| sub_model | [64] | 子模型ID | 数值输入 |
| anim_speed | [69] | 动画速度 | 数值输入 |

### 脚本组
| key | 索引 | 标签 | 控件 |
|-----|------|------|------|
| cur_define | [28] | 当前DEFINE | 数值输入 |
| defunit_idx | [44] | DefUnit索引 | 数值输入 |
| max_A/B/C | [30-32] | 子场景最大A/B/C | 数值输入 |
| cur_A/B/C | [33-35] | 子场景当前A/B/C | 数值输入 |
| head_A/B/C | [39-41] | DefUnit链头A/B/C | 数值输入 |

### 交互/角色组
| key | 索引 | 标签 | 控件 |
|-----|------|------|------|
| char_id | [50] | 所需角色ID | 数值输入 |
| picture_id | [51] | 图片ID | 数值输入 |
| anim_handle | [52] | 动画句柄 | 数值输入 (通常运行时) |

## 不编辑的运行时字段 (只读提示)
- [4] tick — sub_40C388 运行时写入
- [8] sub_flags — 运行时标志
- [12] timer — 等待计时器
- [14] frame_idx, [16] frame_count, [17] frame_cur — 动画帧状态
- [42] script_PC, [43] saved_PC — 脚本执行状态
- [56-57] saved_x/y — 路径备份
- [60-61] dest_x/y — 移动目标
- [65] sub_handle, [67-68] cur/max_frame — 运行时动画
- [70] moving — 移动标志
