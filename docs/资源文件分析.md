# 剧情相关

1. 常规行走图

文件：Cha.JVG

说明：用于普通剧情地图角色的静态站立和行走的图片

作用：一般用于剧情地图上，与角色战斗不相关，在`TKMat.dat`中可以随便更改

相关：TKMat.dat

2. 常规动画

文件：Ani.JVG

说明：用于普通剧情地图中的各种动画

作用：一般用于剧情地图上的背景动画，事件动画，地图动画，特效动画等

相关：TKMat.dat

3. 剧情文本

文件：TKT.dat

说明：用于普通剧情地图中的各种文本

作用：所有需要文本显示的地方

相关：TKMat.dat WarPC.dat TKItem.dat

# 战斗相关

1. 战斗待机图

文件：Awt.JVG

说明：用于战斗地图角色手持武器的待机动作

作用：角色进入战斗时默认等待时的动画序列帧图片

相关：WarPC.dat

2. 战场行走图

文件：Awk.JVG

说明：用于战斗地图移动行走动作

作用：角色在战斗界面四方向行走的动画序列帧图片

相关：WarPC.dat

3. 角色战斗头像

文件：Fa.JVG

说明：用于角色在战斗时显示的头像

作用：角色在战斗界面待机或者时序界面显示的角色头像

相关：WarPC.dat

4. 角色菜单界面头像

文件：Mu.JVG

说明：在右键菜单或者存档界面显示的队伍中的角色头像，原游戏内写死，新编辑器通过扩展字段进行扩充

作用：在右键菜单或者存档界面显示的队伍中的角色头像

相关：WarPC.dat

5. 角色历史介绍

文件：TKT.dat

说明：在队伍菜单中的历史标签页下显示的角色历史介绍，原游戏内写死，新编辑器通过扩展字段进行扩充

作用：在队伍菜单中的历史标签页下显示的角色历史介绍

相关：WarPC.dat
