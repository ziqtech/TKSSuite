## 2. 技能 -> TKKon 配置表

`sub_435D68`（敌方 AI 技能选择）直接读取：

```c
word_9D6C7A = word_9D707A[527 * unit + 273 + skill];
if (word_9D6C7A > 0)
    qmemcpy(&byte_9D6C28, 40 * word_9D6C7A + TKKonBase, 0x28);
```

因此 `[273]-[525]` 是“技能索引 -> TKKon 配置索引”表，共 253 个槽位。

全量统计显示这些值落在 0-649 区间，与 TKKon/TKAct 索引范围一致：

| 字段组 | 典型值 | 判定 |
| --- | --- | --- |
| [277]-[282] | 639 | TKAct 索引 |
| [317]-[341] | 584-608 | TKAct 索引 |
| [357]-[371] | 569-583 | TKAct 索引 |
| [374]-[430] | 40-54、131-132 等 | TKAct 索引 |
| [432]-[520] | 55-638 等 | TKKon/TKAct 索引 |

> `[526]` 是表尾槽位，但运行时被复用为 Cha.JVG 立绘 ID。
