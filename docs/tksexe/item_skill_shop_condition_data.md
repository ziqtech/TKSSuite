# 物品 / 技能 / 商店 / 条件数据模块

> 覆盖 `TKItem.dat`、`TKSkill.dat`、`TKShop.dat`、`TKKon.dat` 的格式、字段、引用关系与扩展限制。

## 1. TKItem.dat

| 属性 | 值 |
| --- | --- |
| 压缩 | LZSS |
| 解压后 | 38400 字节 |
| 记录 | 64 字节 = 32 × int16 |
| 上限 | 600 条 |

关键字段：

| 字段 | 说明 |
| --- | --- |
| [0] | 物品唯一 ID |
| [1] | 菜单/商店分页类别码 |
| [2]/[3] | 名称/描述 TKT ID |
| [4] | Mu.JVG 图标索引，显示时 +130 |
| [5] | 使用权限位掩码 |
| [7]-[10] | HP/MP 上限增加与回复，>1000 为百分比 |
| [11]-[18] | 八项属性加成 |
| [21] | 附加技能索引 -> TKSkill |
| [22]-[24] | 装备/使用后学习技能 -> TKSkill |
| [25] | 增加医术 |
| [26]-[29] | 导致/解除状态掩码 |
| [31] | 价格 |

## 2. TKSkill.dat

| 属性 | 值 |
| --- | --- |
| 压缩 | LZSS |
| 解压后 | 32900 字节 |
| 记录 | 94 字节 |
| 上限 | 350 条 |

技能类型：

| type | 含义 |
| --- | --- |
| 0 | 指令/母技能 |
| 1 | 主动技能 |
| 2 | 被动/反应技能 |
| 3 | 移动技能 |

技能通过 8 组 `(目标技能, 进度权重)` 形成学习树；被动技能通过 WarPC[86-87] 与 TKItem[21] 应用。

## 3. TKShop.dat

| 属性 | 值 |
| --- | --- |
| 压缩 | LZSS |
| 解压后 | 1920 字节 |
| 记录 | 8 字节 |
| 上限 | 240 条 |

字段：

| 偏移 | 字段 | 说明 |
| --- | --- | --- |
| 0 | area_id | 商店区域 0/1/2/3/4/9 |
| 2 | item_ref | TKItem 数组下标 |
| 4 | condition | 幸运偏移或 1=随机抽选 |
| 6 | display | 显示状态 |

商店条件：`显示概率 = clamp(队伍最大幸运 - condition, 0, 100)%`；`condition=1` 走随机抽选，最多 5 件；`condition<=-100` 为始终出现。

## 4. TKKon.dat

| 属性 | 值 |
| --- | --- |
| 压缩 | LZSS |
| 解压后 | 26000 字节 |
| 记录 | 40 字节 = 20 × int16 |
| 上限 | 650 条 |

`field[3]` 是 TKAct 动画索引（`tkact_id`，0-649，-1 表示无动画），不是条件唯一 ID；实际 650 条中该字段有 605 个不同值。`field[15]-[18]` 始终为 0；`field[19]` 为执行标志。TKKon 记录是技能/物品的动作配置，由 `WarPC[273+skill]` 与 `TKItem[6]` 引用。

## 5. 交叉引用

```text
TKItem[2/3]  -> TKT.dat
TKItem[4]    -> Mu.JVG
TKItem[21-24]-> TKSkill.dat
TKShop[2]    -> TKItem.dat 下标
TKKon[3]      -> TKAct.dat 动画索引
TKKon[4]-[14] -> 伤害/回复/状态/时序效果
TKKon[19]     -> 执行标志
WarPC[73-76] -> TKItem.dat
WarPC[82-87] -> TKSkill.dat
WarPC[273+skill] -> TKKon.dat 动作配置
```

## 6. 扩展限制

| 文件 | 固定上限 | 扩展方式 |
| --- | --- | --- |
| TKItem | 600 | 复用空槽，不能增加文件长度 |
| TKSkill | 350 | 需代码补丁扩展技能表 |
| TKShop | 240 | 固定 8 字节记录，不能增条目 |
| TKKon | 650 | 固定 40 字节记录 |
