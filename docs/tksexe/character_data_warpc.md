# WarPC.dat 角色数据模块

> 分析对象：`WarPC.dat` 运行时角色数据、字段布局、引用关系与扩展限制。
> 详细字段表见 [`逆向工作区/docs/04_战斗与角色数据/WarPC角色数据字段分析.md`](../../../逆向工作区/docs/04_战斗与角色数据/WarPC角色数据字段分析.md)。

## 1. 文件格式

| 属性 | 值 |
| --- | --- |
| 压缩 | LZSS 变种 |
| 解压后大小 | 150722 字节 |
| 记录大小 | 1054 字节 = 527 × int16 |
| 记录数 | 143 |
| 加载 | `sub_45343C` -> `sub_452B14` |

## 2. 关键字段

| 偏移 | 字段 | 说明 |
| --- | --- | --- |
| [0] | name_id | 角色名 TKT ID |
| [1] | portrait | 立绘/头像索引 |
| [2] | level | 等级 |
| [3] | role/faction | -1 我方，0 敌方 |
| [4] | exp_to_next | 升级所需经验，`8*level^2 + 92` |
| [5]-[10] | HP/MP 当前与上限 | 运行时属性 |
| [11]-[26] | 八项属性基础/当前 | 攻击、防御、命中、闪避、速度、幸运、悟性、移动 |
| [31] | exp/jp | 经验/技能点，与等级强相关 |
| [67]-[68] | cause_mask | 导致状态掩码 |
| [69]-[76] | equip 槽 | 4 个运行时索引 + 4 个物品 ID |
| [82]-[87] | 装备/被动技能 | 指向 TKSkill |
| [88]-[526] | 大量未直接引用字段 | 大部分保留值，不轻易改 |

## 3. 引用关系

```text
WarPC[0]     -> TKT.dat  角色名
WarPC[73-76] -> TKItem.dat 装备物品 ID
WarPC[82-87] -> TKSkill.dat 装备/被动技能索引
存档 Frame2  -> 序列化 WarPC 150722 字节
```

## 4. 运行时关键函数

| 地址 | 函数 | 职责 |
| --- | --- | --- |
| `0x004173F8` | LoadAllData | 加载并匹配装备索引 |
| `0x0042234C` | ApplyEquip | 装备/技能/属性应用 |
| `0x0041E40C` | UseItem | 物品使用与属性变更 |
| `0x00422BBC` | ApplyPassive | 被动/移动/主动技能效果 |
| `0x0040E11C` | Attribute | 脚本修改角色属性 |
| `0x0040DA00` | TeamMember | 角色入队/离队 |

## 5. 扩展限制

- 原版固定 143 条 × 1054 字节。
- 启动器通过补丁扩展 WarPC 缓冲区，并同步修补 150722 / 159922 存档常量。
- 未使用字段不得随意改写，避免破坏运行时推导。
