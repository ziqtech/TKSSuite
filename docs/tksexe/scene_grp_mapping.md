# 场景 ID -> SC.GRP Section 精确映射

> 结论：`scene_id` 直接作为 `SC.IDX` 下标，`SC.GRP` 区段索引就是场景 ID。

## 1. 证据链

```text
TForm1_FormCreate
  sub_452544("SC.IDX", Offset, 860)   -> Offset = SC.IDX (215 x uint32)
  dword_4FA50C = fopen("SC.GRP", "rb")

ChangeScene(scene_id, x, y, dir)
  -> sub_40C044
  -> sub_402B88(scene_id)
  -> fseek(dword_4FA50C, Offset[scene_id], 0)
  -> sub_411308(dword_4FA50C)
      读取 [2B width][2B height][4B frameA_size][4B frameB_size][data]
      Frame A: LZSS RGB565 背景
      Frame B: RLE 深度 mask
```

## 2. 关键结论

- `SC.IDX` 共 215 个 uint32 偏移，前 214 个对应 section 0-213，最后一个为文件大小哨兵。
- TKD 中 `ChangeScene` 实际使用的场景 ID 全部落在 0-213，无越界。
- `WSC.GRP` 不参与 `ChangeScene`；`sub_402BB8 -> sub_42FA50` 使用 `WSC.IDX`，属于战斗/特殊背景路径。
- 场景名从 `TKT.dat` 的 `scene_id + 300` 条目读取。
