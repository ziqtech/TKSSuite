# 运行时内存布局与关键全局变量

> 汇总 TKS.exe 运行时最常被逆向引用的全局状态，便于跨模块交叉定位。

## 1. 实体与脚本

| 变量 | 大小 | 含义 |
| --- | --- | --- |
| `dword_51AF40` | 2304000 | TKMat 实体表，6000×384 |
| `dword_753500` | 80000 | DEFINE 表，5000×16 |
| `dword_755A94` | 指针 | 当前脚本字节码指针 |
| `word_755AB2` | 2B | 脚本 PC |
| `dword_755AAC` | 4B | 条件跳转/Else 深度 |
| `dword_75350C` | 4B | 当前执行实体 ID |
