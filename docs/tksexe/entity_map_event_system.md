# 实体/地图/事件系统

## 1. 核心数据

### TKMat.Dat

- 大小：2,304,000 字节
- 结构：6000 条 × 384 字节
- 内存：`dword_51AF40[]`
- 每条 = 96 × int32

### TKDefUnit.dat

- 大小：80,000 字节
- 每条 16 字节
- 记录实体脚本阶段链

## 3. 实体类型

| 值 | 类型 | 渲染/行为 |
| --- | --- | --- |
| 0 | 空槽 | 跳过 |
| 5 | 入口/传送点 | 不绘制动画 |
| 10 | 地形块 | `sub_4526D0` 绘制 |
| 15 | 障碍物 | 阻挡 |
| 16 | 建筑/门 | 特殊脚本 |
| 20 | 事件对象 | Ani.jvg 动画 |
| 110 | 特殊机关 | `dword_755AC0[anim_set]` |
| 200 | NPC/角色 | Cha.jvg + Ani.jvg |

## 4. 实体调度

`sub_409618`：

```text
遍历当前场景实体表 dword_74D740[]
按 flags 启用/禁用
推进 timer/tick
按类型调用：
    20/200 -> sub_408704
    16     -> sub_4084E0
    10     -> sub_4081F8
    15     -> sub_408408
执行实体脚本 sub_40EBD4
```

## 5. 脚本阶段链

TKDefUnit 16 字节记录：

```text
[f0/f1]  DEFINE ID 低/高 16 位
[f4/f5]  第二槽 DEFINE ID
[f6]     链下一节点
```

DEFINE ID：

```text
DEFINE_ID = (entity_id << 16) | block_id
```

实体 [44] 保存当前 DefUnit 记录；`sub_4066F0` 按 `cur_A/B/C` 沿 f6 链推进。

## 6. 子场景 A/B/C

| 字段 | 作用 |
| --- | --- |
| max_A/B/C | 各链最大阶段 |
| cur_A/B/C | 当前阶段 |
| head_A/B/C | 链头 |

脚本 `End` 操作码参数可推进/重置：

```text
参数 1/2/3 -> cur_A/B/C += 1
参数 4/5/6 -> cur_A/B/C = 0
```

## 7. 事件执行

实体启用后：

```text
if script_PC == -1:
    sub_4066F0 初始化脚本入口
    script_PC = 0
sub_40EBD4 执行 DEFINE 字节码
```

脚本通过 `SetFlag/AddFlag/SetSwitch/SetVar` 修改全局状态。

## 8. 关键函数

| 地址 | 功能 |
| --- | --- |
| `0x00405CBC` | 实体动画/渲染初始化 |
| `0x00409618` | 实体调度 |
| `0x004066F0` | DefUnit 链推进 |
| `0x0040EBD4` | 脚本执行 |
| `0x004081F8` | 类型 10 地形逻辑 |
| `0x004084E0` | 类型 16 建筑/门逻辑 |
| `0x00408704` | 类型 20/200 事件/NPC 逻辑 |

## 9. 结论

地图事件系统是“TKMat 实体表 + TKDefUnit 阶段链 + TKD DEFINE 脚本”三层结构：

```text
TKMat 实体 -> TKDefUnit 阶段 -> DEFINE 脚本 -> 修改实体/全局状态
```
