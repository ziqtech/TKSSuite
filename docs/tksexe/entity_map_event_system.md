# 实体/地图/事件系统

## 1. 核心数据

### TKMat.Dat

- 大小：2,304,000 字节
- 结构：6000 条 × 384 字节
- 内存：`dword_51AF40[]`
- 每条 = 96 × int32

### TKDefUnit.dat

- 大小：80,000 字节
- 每条 16 字节
- 记录实体脚本阶段链

## 3. 实体类型

| 值 | 类型 | 渲染/行为 |
| --- | --- | --- |
| 0 | 空槽 | 跳过 |
| 5 | 脚本对象 | 无专用 tick，主要执行 `sub_40EBD4` 脚本 |
| 10 | 出入传送点 | `sub_4081F8` 传送 + 地形路径 |
| 15 | 事件触发区 | `sub_408408` 玩家碰撞触发脚本 |
| 16 | 随机战斗区 | `sub_4084E0` 概率触发 `sub_40EB10` 战斗 |
| 20 | 事件对象 | Ani.jvg 动画，`sub_408704` |
| 110 | 特殊机关 | `dword_755AC0[anim_set]`，`sub_408B30` |
| 200 | NPC/角色 | Cha.jvg + Ani.jvg |

## 4. 实体调度

`sub_409618`：

```text
遍历当前场景实体表 dword_74D740[]
按 flags 启用/禁用
推进 timer/tick
按类型调用：
    20，或 200 且 moving==1 -> sub_408704
    16     -> sub_4084E0
    10     -> sub_4081F8
    15     -> sub_408408
    5      -> 无专用 tick，直接执行脚本
执行实体脚本 sub_40EBD4
```

## 5. 脚本阶段链

TKDefUnit 16 字节记录（按 dword 索引）：

```text
dword0  DEFINE ID（32 位）
dword1  编译后脚本指针
dword3  链下一 DefUnit 索引
```

`sub_4066F0` 按 `cur_A/B/C` 从 `head_A/B/C` 出发，沿 `dword3` 推进。

DEFINE ID：

```text
DEFINE_ID = (entity_id << 16) | block_id
```

实体 [44] 保存当前 DefUnit 记录；运行时脚本指针写入 [42]/[43]。

## 6. 子场景 A/B/C

| 字段 | 作用 |
| --- | --- |
| max_A/B/C | 各链最大阶段 |
| cur_A/B/C | 当前阶段 |
| head_A/B/C | 链头 |

脚本 `End` 操作码参数可推进/重置：

```text
参数 1/2/3 -> cur_A/B/C += 1
参数 4/5/6 -> cur_A/B/C = 0
```

## 7. 事件执行

实体启用后：

```text
if script_PC == -1:
    sub_4066F0 初始化脚本入口
    script_PC = 0
sub_40EBD4 执行 DEFINE 字节码
```

脚本通过 `SetFlag/AddFlag/SetSwitch/SetVar` 修改全局状态。

## 8. 关键函数

| 地址 | 功能 |
| --- | --- |
| `0x00405CBC` | 实体动画/渲染初始化 |
| `0x00409618` | 实体调度 |
| `0x004066F0` | DefUnit 链推进 |
| `0x0040EBD4` | 脚本执行 |
| `0x004081F8` | 类型 10 出入传送逻辑 |
| `0x004084E0` | 类型 16 随机战斗区逻辑 |
| `0x00408704` | 类型 20/200（moving=1）事件/NPC 逻辑 |

## 9. 结论

地图事件系统是“TKMat 实体表 + TKDefUnit 阶段链 + TKD DEFINE 脚本”三层结构：

```text
TKMat 实体 -> TKDefUnit 阶段 -> DEFINE 脚本 -> 修改实体/全局状态
```
