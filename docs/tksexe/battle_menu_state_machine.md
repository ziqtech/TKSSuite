# 战斗菜单状态机 sub_447DAC

> 地址：`0x00447DAC`
> 文件：`decompile/447DAC.c`
> 作用：处理战斗中的玩家/单位行动选择、移动、目标确认、技能/道具执行。

## 4. 状态转换示例

### 普通攻击

```text
0 -> 1 (选择攻击)
1 -> 4 (确认普通攻击)
4 -> 5 (移动后攻击)
5 -> sub_4458B0()
```

### 技能

```text
1 -> 10 (普通技能)
10 -> 14 (选择目标)
14 -> sub_4458B0()

1 -> 12 (硬编码技能)
12 -> 14/执行
```

### 道具

```text
1 -> 20
20 -> 22
22 -> 消耗道具并 sub_4458B0()
```

### 异位

```text
12 -> 40 -> 42
42 -> 交换两个单位 -> sub_4458B0()
```

## 5. 移动流程

状态 `2`：

- 左键移动到目标格。
- 右键取消移动，返回状态 `1`。

移动后进入目标选择状态 `3`。

## 6. 目标确认

所有目标选择状态都检查：

```text
byte_952D54[光标格] == 1
```

合法后写：

```text
word_9D6F7C = 光标X
word_9D6F7E = 光标Y
byte_9D6FA4[] = 目标单位
byte_9D6FC4 = 目标数
```

然后调用 `sub_4458B0()` 执行。

## 7. 取消/返回

右键：

```text
状态 4/5/10/11 等 -> 返回 1/3
状态 2 -> 返回 1
状态 22/23 -> 返回 20/21
```

## 9. 结论

`sub_447DAC` 是战斗交互层，负责把玩家/单位意图转换成动作队列，再交给 `sub_4458B0` 执行。修改战斗菜单时，应优先改这里的状态转换和动作码。
