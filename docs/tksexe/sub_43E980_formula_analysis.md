## 5. 伤害减伤公式

核心公式：

```text
攻击 = 基础值
防御 = word_9D7096[target]

word_9DF7C2[target] & 0x1000: 防御 += 60%
byte_9E0494[target]: 防御 += 30%
byte_9E04AA[target]: 防御 += 40%
byte_9E048F[target]: 防御 -= 30%
byte_9E04A6[target]: 防御 -= 30%

伤害 = 攻击² / (攻击 + 3 * 防御)
      + random(攻击² / (攻击 + 2 * 防御)
               - 攻击² / (攻击 + 3 * 防御) + 1)
```

若 `byte_9E04A4[target]` 非零，最终伤害翻倍。

## 8. 治疗/恢复评分

当 `word_9D6C60` 或 `word_9D6C62` 非零：

- 只有 50% 概率计入评分。
- 只对 HP/MP 低于上限 25% 的目标产生价值。
- 恢复量按目标缺失量钳制。
- 目标标志 1 时恢复 ×3，标志 2 时恢复 +50%。
- 对友军加分，对敌方扣分。
