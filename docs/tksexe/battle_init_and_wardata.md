# 战斗初始化与 WarData/WarWay

## 1. 文件格式

### WarData.dat

- 每条战争记录 498 字节。
- 加载函数 `sub_42FDF8`：

```c
fseek(file, 498 * war_id, SEEK_SET);
fread(&byte_9537D8, 0x1F2, 1, file);   // 0x1F2 = 498
```

### WarWay.dat

- 每块 1024 字节。
- 加载函数 `sub_42FE70`：

```c
fseek(file, word_9537F8 << 10, SEEK_SET);
fread(&unk_951942, 0x400, 1, file);   // 0x400 = 1024
```

`word_9537F8` 是当前战争的地图块索引。

## 2. 战斗初始化 sub_436BD4

地址：`0x00436BD4`

流程：

```text
加载 SWS.GRP/SWS.IDX
清零掉落队列、状态、等级、AI 标志
设置战争 ID word_4EB728
加载 WarData.dat 当前记录
加载 WarWay.dat 当前地图块
加载战斗 JVG 动画
解析 TKD DEFINE
sub_4307CC 初始化单位
sub_431428 初始化地图网格
清零经验/JP/金钱/掉落计数
```

## 4. 单位初始化 sub_4307CC

地址：`0x004307CC`

- 清零战斗单位数组 `word_9D707A[]`。
- 初始化 6 个队伍槽位。
- 把永久队伍数据复制到战斗结构，每单位 527 word。
- 根据 WarPC 头像/动作字段选择动画：
  - `word_9D6C84`
  - `dword_9DF43A[]`
- 生成敌方单位：
  - 读取 `word_9537FA[]` 敌方配置
  - 根据 WarPC 索引 `v26 + 35`
  - 通过 `sub_430578` 随机化等级/属性
- 记录单位总数 `byte_9DF886`。
- 计算平均属性 `word_9D6C86`。

## 5. 地图网格 sub_431428

地址：`0x00431428`

- 初始化 `byte_951D42[]` 为 -1。
- 把友军/敌军坐标写入占用网格。
- 根据 `unk_951942[]` 的 1-5 号地形/区域标记生成候选出生点。
- 随机分配 24 个预设出生点 `unk_953866[]`。
- 建立每个单位的网格索引 `word_9DF802[]`。

## 6. WarData 关键字段

现有资料已确认的部分：

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | byte | flags，`&4`=随机敌军 |
| 1.. | bytes | 敌人生成配置 |
| 482-483 | uint16 | `word_9539BA` 回合限制 |

完整字段分析可参考：

- `docs/wardata_editor/`
- `docs/mat_editor/随机战斗机制逆向分析.md`

## 7. 结果

战斗初始化是“固定文件记录 + 运行时随机化”：

- 战场布局来自 WarData/WarWay
- 敌人等级/属性由 `sub_430578` 随机化
- 地图出生点由 `sub_431428` 根据地形候选随机选择
