# 存档系统运行时写读链路

> 分析对象：`sub_42131C`（存档/读档主控）、`sub_410ED4`（SaveTKMat）、`sub_41103C`（LoadTKMat）、`sub_41CE10`（索引写入）、`sub_41B1A8`（索引读取）。
> 依据：`decompile/42131C.c`、`410ED4.c`、`41103C.c`、`41CE10.c`、`41B1A8.c` 及实际存档二进制交叉验证。

## 1. 文件层

| 文件 | 用途 |
| --- | --- |
| `save\sav.%d` | 完整游戏状态，双 Frame LZSS 压缩 |
| `save\%d.sav` | 28 字节 UI 摘要索引 |

槽位路径由同一公式生成：

```text
slot = (cursor_x + 1) / 2 + 3 * page
```

## 2. 主存档 `sav.%d`

### 2.1 两层 Frame

```text
Frame 1:
  [4B frame_total_size]
  [4B original_size = 2304000]
  [LZSS(TKMat 实体表, dword_51AF40)]

Frame 2:
  [4B frame_total_size]
  [4B original_size = 159922]
  [LZSS(BlockA + BlockB + WarPC)]
```

Frame 2 子块：

| 块 | 偏移 | 大小 | 源内存 |
| --- | --- | --- | --- |
| A | 0 | 3432 | `unk_755B18`，SCE 全局标志/变量/事件数组 |
| B | 3432 | 5768 | `unk_756880`，背包/任务/队伍/统计等 |
| C | 9200 | 150722 | `word_757F08`，WarPC 运行时角色数据 |

### 2.2 保存路径

`sub_42131C` 在存档菜单触发后调用 `sub_410ED4("save\\sav.%d", slot)`：

1. `sub_4530A8` 压缩 `dword_51AF40`（2304000 字节）为 Frame 1。
2. 分配 159922 字节，按 `0 / 3432 / 9200` 拼接三块全局状态。
3. `sub_4530A8` 压缩拼接缓冲为 Frame 2。
4. 依次写 `[frame_size][frame_data]`，然后关闭文件。

### 2.3 读取路径

`sub_42131C` 或标题画面 `sub_426164` 调用 `sub_41103C("save\\sav.%d", slot)`：

1. 读 Frame 1，`sub_452B14` 解压到 `dword_51AF40`。
2. 读 Frame 2，解压到 159922 字节临时缓冲。
3. 按 `0 / 3432 / 9200` 三块复制回 `unk_755B18`、`unk_756880`、`word_757F08`。
4. 记录旧场景 `v8 = dword_755B58`，把 `dword_755B58` 设为 `-1` 强制重载。
5. 重建玩家/摄像机指针，调用 `sub_40C044(v8, x, y, dir)` 加载场景，再恢复交互状态。

## 3. 索引文件 `%d.sav`

28 字节：

| 偏移 | 大小 | 内容 |
| --- | --- | --- |
| 0 | 6×1B | 队伍成员 ID（`word_75688C`，低字节，-1=空） |
| 6 | 2B | 金钱 `word_756882` |
| 8 | 4B | Unix 时间戳 |
| 12 | 6×2B | 各队员等级 `word_757F0C[527*id]` |
| 24 | 4B | 当前控制角色/场景 `dword_755B58` |

注意：队伍成员 ID 只写低字节，超过 255 会在列表显示截断。

## 4. 硬编码常量与补丁风险

| 常量 | 含义 | 当前补丁状态 |
| --- | --- | --- |
| 2304000 | TKMat 实体表 | 未修补 |
| 3432 / 5768 | Block A/B | 未修补 |
| 9200 | Frame 2 中 WarPC 偏移 | 未修补 |
| 150722 | WarPC 原始大小 | 启动器已修补 |
| 159922 | Frame 2 总大小 | 启动器已修补 |

若未来扩展 WarPC，`150722` 与 `159922` 需同步；若扩展 Block A/B，`9200` 偏移也必须同步修改。

## 5. LZSS 特征

- 压缩：`sub_4530A8`，4096 字节窗口，初始填充 0x20，最小匹配约 3 字节，最大 18 字节。
- 解压：`sub_452B14`，头部 4 字节为原始大小。
- 非标准 zlib，需按反编译算法实现专用读写器。

| 地址 | 函数 | 职责 |
| --- | --- | --- |
| `0x00421C` 系列 | `sub_42131C` | 菜单状态机，触发保存/读取 |
| `0x00410ED4` | SaveTKMat | 写主存档 |
