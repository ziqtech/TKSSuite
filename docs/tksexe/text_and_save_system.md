# 文本与存档系统

## 1. TKT.dat 文本库

文件：`TKT.dat`

- XOR `0xFF` 加密
- Big5/CP950 文本
- 加载：`sub_401E88`
- 若有 `TKTalk.txt`，可重新生成 `TKT.dat`
- 文本查询：`sub_4067E8`
- 文本渲染：`sub_44E49C`

| --- | --- |

| `0x15` | VARNUM |
| `0x16` | VARTXT |
| `0x1D` | NAME |

## 4. 存档文件

### sav.N 主存档

结构：

```text
Frame 1:
  [4B total_size]
  [4B original_size = 2304000]
  [LZSS(TKMat 实体表)]

Frame 2:
  [4B total_size]
  [4B original_size = 159922]
  [LZSS(BlockA + BlockB + WarPC)]
```

Frame 2 子块：

| 块 | 偏移 | 大小 | 内容 |
| --- | --- | --- | --- |
| A | 0 | 3432 | SCE 全局变量/标志 |
| B | 3432 | 5768 | 背包/任务/队伍/金钱 |
| C | 9200 | 150722 | WarPC 角色数据 |

WarPC：

```text
143 角色 × 1054 字节
```

### N.sav 存档索引

28 字节：

```text
[6 x 1B] 队伍角色 ID
[2B]     金钱
[4B]     Unix 时间戳
[6 x 2B] 队伍等级
[4B]     场景/角色 ID
```

## 5. 存档槽位

游戏内槽位索引：

```text
(arglist[614870] + 1) / 2 + 3 * arglist[614900]
```

实际槽位文件：

```text
save\%d.sav    主存档
save\sav.%d    存档索引/元数据
```

## 6. 保存/读取函数

| 地址 | 功能 |
| --- | --- |
| `0x00410ED4` | SaveTKMat/写存档 |
| `0x00411DAC` | 刷新/显示 |
| `0x00411DFC` | 线程对象创建 |
| `0x0041CE10` | 写存档索引 |
| `0x0041B1A8` | 读存档列表 |
| `0x00421C?` | 读存档 |

## 7. 结论

存档系统分为两层：

```text
主存档: 实体表 + 全局状态 + WarPC
索引: 队伍摘要，用于界面显示
```
