# 战斗 AI 决策分析

> 分析对象：`sub_436678`、`sub_435D68`、`sub_4359A4`、`sub_43E980`，以及目标/效果网格函数。

## 1. 总流程

```text
sub_436678 (回合行动入口)
  |
  |-- 玩家方: sub_4359A4(byte_9D6D32)
  |-- 敌方:   sub_435D68()
  |
  |-- sub_4359A4: 扫描 byte_952954 / byte_952D54
  |     每个候选点调用 sub_43D8B0 建立效果网格
  |     再调用 sub_43E980 计算行动价值
  |
  |-- 有分: 选定技能/目标 -> sub_4458B0 执行
  |-- 无分: 寻找最近敌人 -> 移动到可达格
  |     若不可移动 -> 50% 待机 / 50% 防御
```

## 2. 回合行动入口 `sub_436678`

地址：`0x00436678`

根据 `byte_9DF761[word_9D6F58]` 分派：

| 阵营 | 行为 |
| --- | --- |
| `10` | 特殊单位，不执行通用 AI 评估 |
| `100` | 玩家方，调用 `sub_4359A4` |
| 其他 | 敌方，调用 `sub_435D68` |

选定行动后：

- 如果目标点就是当前格，使用攻击点与目标点的中点。
- 否则把光标移动到“当前点 + 目标点”的中点。
- 普通攻击时 `word_9DF6FA += byte_4EB72D`。
- 技能时 `word_9DF6FA += word_7861F2[47 * skill]`。
- 最终调用 `sub_4458B0` 执行动作。

## 3. 敌方技能选择 `sub_435D68`

地址：`0x00435D68`

- 先默认普通攻击：`word_9D6C7C = -1`，用 `sub_4359A4` 得到普通攻击评分。
- 读取 AI 技能池 `word_9D6D1E`、`word_9D6D20`。
- 对每个 `< 1000` 的技能 ID：
  - 技能有硬编码行为时调用 `sub_438F28` 入队；
  - 否则读取该单位的技能配置 `word_9D707A[527 * unit + 273 + skill]`；
  - 配置存在时用 `sub_4359A4` 重新评分。
- 保留评分最高的技能；如果评分 `> 0`，写回：

```text
word_9D6C7C = 技能ID
word_9D6C7A = 技能配置ID
word_9DF6FA = 行动时间消耗
```

## 4. 全图扫描 `sub_4359A4`

地址：`0x004359A4`

- 输入 `a1 != 0` 时扫描整个 `byte_952954`（可达/移动网格）：
  - 对每个可达格调用 `sub_43D53C` 建立目标候选网格。
  - 对目标网格中标记为 `1` 的每个点，再调用 `sub_43D8B0` 建立效果网格。
  - 有目标时调用 `sub_43E980` 得到评分。
- 输入 `a1 == 0` 时只评估当前格周围的目标。
- 记录最优结果：

```text
word_9DF896 / word_9DF898 = 施法/移动起点
word_9DF89A / word_9DF89C = 效果/目标点
```

- 平手时 20% 随机替换，或者比较当前格候选优先级。

## 5. 行动价值评分 `sub_43E980`

地址：`0x0043E980`

返回一个带符号 int16，`sub_4359A4` 取最大值。

评分由三部分叠加：

### 5.1 基础伤害/效果值

- `word_9D6C58` 为本次动作基础值。
- `0xFFFF` 时按施法者面板 `word_9D7092[]` 计算。
- 技能 105/106/113/114/118/128 等有专用倍率。
- 超过 1000/2000/3000 时做分级修正。

### 5.2 命中/抗性修正

- 命中基础 `v43 = 攻击力 + 50 - 目标防御`。
- 根据动作范围类型 `word_9D70BA[attacker]` 做 5%/15%/25%/50% 递减。
- 命中钳制在 `10..95`。
- 技能 200/219 对低等级目标有特殊命中。

### 5.3 敌我正负号

```text
同一阵营:
    v42 = v41 - 命中
    非致命: v41 = v42 - 伤害
    致命:   v41 = v42 - 3 * 伤害

敌对阵营:
    v42 = v41 + 命中
    非致命: v41 = v42 + 伤害
    致命:   v41 = v42 + 3 * 伤害

目标是自己:
    非致命: v41 -= 300
    致命:   v41 -= 3000
```

### 5.4 状态效果价值

- 对敌人施加减益：`-2/3/5 × 敌方属性`。
- 对友军施加增益：`+2/3/5 × 友军属性`。
- `0x2000/0x4000` 掩码有额外 5/6/8 倍加成。

## 6. 目标与效果网格

### `sub_43D53C`

地址：`0x0043D53C`

- 根据动作范围配置 `byte_9D6C28..2D` 生成 `byte_952D54`。
- `1` = 合法目标格。
- 目标过滤规则：
  - 地图占用 `byte_951D42` 为空地时可选
  - 阵营匹配按 `byte_9D6C2C/2D` 控制

### `sub_43D8B0`

地址：`0x0043D8B0`

- 根据技能/动作范围生成 `byte_953154` 效果网格。
- 特殊技能 242：随机决定 `word_9D6C30` 或 `word_9D6C38` 为 50。
- 范围扩张依赖 `byte_951942` 的阻挡信息。

## 7. 移动回退

当 AI 找不到任何有效行动（评分 `0`）时：

- 若 `byte_9D6F84[unit] < 0`，进入移动逻辑。
- `sub_436114`：从 `byte_9D705A[]` 遍历参战单位，找最近敌人。
- `sub_4364EC`：在 `byte_952954` 中选择离敌人最近的合法移动格。
- 无合法移动格：
  - 50% 待机，`word_9DF6FA = byte_4EB72F[0]`
  - 50% 防御，`word_9DF7C2[unit] |= 0x1000`，`word_9DF6FA = byte_4EB72E`

## 9. 结论

AI 决策本质是“穷举所有可达格 × 所有目标格 × 可用技能，选行动价值最高的组合”：

```text
行动价值 = 伤害/治疗价值
          ± 命中价值
          ± 状态价值
          - 对己方/自身造成的负面后果
```

由于评分函数同时包含敌我判断、击杀奖励、状态价值和自我惩罚，所以敌方 AI 会优先击杀低血量玩家、回避误伤友军，并根据可用技能池选择伤害/治疗/状态中收益最高的动作。
