# 界面、菜单与世界流程

## 1. 主菜单状态机 sub_426164

地址：`0x00426164`

菜单状态字段：`a1[461]`

| 状态 | 含义 |
| --- | --- |
| 0 | 主菜单/标题 |
| 1 | 队伍/状态界面 |
| 6 | 保存界面 |
| 7 | 存档确认 |
| 8 | 读档确认 |
| 9 | 读档列表 |
| 10 | 读取存档并进入游戏 |

资源：

```text
TitleMenu.gxp
Mb.gxp
SSF.GRP/SMG.GRP
```

## 2. 场景切换 sub_40C044

地址：`0x0040C044`

流程：

```text
如果场景 ID 变化:
    切换 BGM byte_755B74[scene]
    加载场景 DEFINE
    初始化实体表 sub_405CBC
设置玩家坐标/朝向
清空实体调度缓存
```

## 3. 世界地图

- 大地图场景：`SWS.GRP/SWS.IDX`
- 普通场景：`SC.GRP/WSC.GRP`
- 玩家通过 `SetWalk/WaitWalk` 移动
- `sub_40B2D0` 处理传送点/边界

## 4. 保存/读取菜单

`sub_41FAAC` 负责：

- 队伍状态
- 角色选择
- 存档列表
- 读档/写档

相关函数：

| 地址 | 功能 |
| --- | --- |
| `0x0041FAAC` | 队伍/存档菜单 |
| `0x0041CE10` | 写存档索引 |
| `0x0041B1A8` | 读存档列表 |
| `0x00421103C` | 读取存档 |

## 5. 对话框

对话资源：

```text
Mu.jvg    菜单头像
Mb.gxp    对话框
pface.jvg 头像
```

对话由脚本 `TalkA/TalkB` 触发，文本来自 TKT.dat。

## 6. 中文输入

`InputChinese` 类：

- 处理中文名/姓名输入
- 使用 IMM 输入法
- 输入缓冲区 `byte_9D6DDA`

## 7. 关键函数

| 地址 | 功能 |
| --- | --- |
| `0x00426164` | 主菜单状态机 |
| `0x0040C044` | 场景切换 |
| `0x0041FAAC` | 队伍/存档菜单 |
| `0x00425EAC` | 标题菜单初始化 |
| `0x0040B2D0` | 世界/场景输入 |
| `0x0040A220` | 对话执行 |

## 8. 结论

游戏流程：

```text
标题 -> Logo/Title -> 主菜单 -> 读档/新游戏
     -> 世界场景 -> 事件 -> 战斗 -> 结局
```
