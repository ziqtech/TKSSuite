# 战斗主循环与战后结算

## 1. 战斗入口

脚本命令 `War` 最终调用 `sub_40EB10`，由 `sub_43CA64` 进入战斗主循环。

## 2. 战斗主循环 sub_43CA64

地址：`0x0043CA64`

流程：

```text
初始化战斗
按玩家平均等级选择 BGM（23/24/25.mp3）

while word_951940 == 0:
    检查回合限制 word_9539BA
    检查行动时间 word_9DF6FA
    执行 AI/玩家行动 sub_436678
    渲染战场
    处理战斗菜单 sub_447DAC
    统计 FPS
```

## 3. 战斗结果码

| `word_951940` | 含义 |
| --- | --- |
| `-2` | 失败/逃跑 |
| `-1` | 失败/逃跑 |
| `1` | 胜利 |
| `2` | 回合限制失败 |

## 4. 战后转场 sub_43BFE8

地址：`0x0043BFE8`

- 停止战斗菜单状态机。
- 播放胜利/失败 BGM 和过渡动画。
- 胜利时调用 `sub_43B7FC` 发放奖励。
- 最后调用 `sub_43BF20` 回写队伍数据。

## 5. 战后奖励 sub_43B7FC

地址：`0x0043B7FC`

### 5.1 统计存活单位

遍历 `word_9D7084[]`：

- 统计存活数。
- 检查死亡/撤退/存活标记。
- 根据经验池和存活人数均分经验。

### 5.2 经验分配

```text
每个存活队员经验 += dword_9D6F14
若队员有经验加成字段:
    经验 += 加成 * 经验 / 100
等级上限 30000
```

升级：

```text
while 经验 >= 所需经验:
    扣除所需经验
    调用 sub_43066C 升级
    回满 HP/MP
```

### 5.3 JP 分配

```text
每个存活队员 JP += dword_9D6F18
若有 JP 加成字段，追加百分比
上限 30000
```

### 5.4 掉落

遍历掉落队列 `word_9D6E14/word_9D6E12`：

```text
数量 > 99 时钳制到 99
sub_40CE30(item_id, qty, 0)
```

### 5.5 金钱

```text
若配置允许:
    金钱 *= random(2..5)
若特殊模式:
    金钱 *= 5
上限 9999
sub_40CE30(10000, gold, 0)
```

## 6. 回写队伍 sub_43BF20

地址：`0x0043BF20`

- 遍历 6 个队伍槽位。
- 存活单位写回永久 WarPC/队伍结构。
- 死亡单位设为 1 HP 并做离场/死亡处理。
- 将战斗属性同步回 `word_758324` 等全局队伍数据。

## 7. 失败/逃跑处理

`word_951940 = -1/-2`：

- 不发放经验/掉落。
- 调用失败过渡。
- 若战场失败条件 `byte_9537D8 & 2` 生效，转为强制失败。

## 8. 关键函数

| 地址 | 功能 |
| --- | --- |
| `0x0043CA64` | 战斗主循环 |
| `0x0043BFE8` | 战后过渡 |
| `0x0043B7FC` | 战后奖励 |
| `0x0043BF20` | 队伍回写 |
| `0x0043066C` | 升级 |
| `0x0040CE30` | 物品/金钱入队 |

## 9. 结论

战斗胜利后的经验、JP、金钱、掉落都在 `sub_43B7FC` 统一结算；改经验倍率、掉落数量和战后恢复逻辑应以该函数为主要入口。
