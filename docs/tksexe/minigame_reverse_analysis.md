# TKS 小游戏逆向分析

> 分析对象：`TKS.exe` 中 `MiniGame` 脚本指令对应的 7 个小游戏。
> 依据：`反编译产物/decompile/` 反编译 + `TKD.dat` 脚本调用上下文。

## 1. 调度链

脚本指令 `MiniGame(type, target, compare)` 由 `sub_40E97C` 分派：

```c
MiniGame(类型, 目标值, 比较模式, &word_755E7E)
```

`sub_40E97C` 会先加载 `SMG.GRP/SMG.IDX`，然后按类型调用对应小游戏主函数：

| 类型 | 资源 | 主函数 | 脚本/剧情对应 |
| --- | --- | --- | --- |
| 1 | `MG_WA.jvg` / `MG_WA.gxp` | `sub_42AC40` | 铁笼/方块机关，限时 5 分钟 |
| 2 | `MG_EIGHT.jvg` / `MG_EIGHT.gxp` | `sub_428DAC` | 八阵图游戏 |
| 3 | `MG_eighteen.jvg` / `MG_eighteen.gxp` | `sub_429C20` | 十八啦/骰子赌博 |
| 4 | `MG_Ball.jvg` / `MG_Ball.gxp` | `sub_42DD88` | 珠子顺序 |
| 5 | `MG_44.jvg` / `MG_44.gxp` | `sub_42ED40` | 十六同数 |
| 6 | `MG_rotate.jvg` / `MG_rotate.gxp` | `sub_42D3A4` | 旋转拼图 |
| 7 | `MG_reverse.jvg` / `MG_reverse.gxp` | `sub_42E414` | 龙蛇拼图 |

小游戏完成后，返回值写入 `word_755E7E`，再按 `compare` 判定：

```c
if (a3 == 1)      return a2 <= result;
else              return a2 >  result;
```

脚本中常见写法为 `MiniGame(type,1,1)`，即只要结果 `>= 1` 就算成功。

## 2. 共享状态

| 内存 | 含义 |
| --- | --- |
| `dword_951560` | 小游戏结果：`-1` 进行中，`0` 失败/退出，`1` 成功 |
| `dword_4EAAFC` | 当前选中/拖动物品的值；`-1` 表示未选中 |
| `dword_951370` / `dword_951374` | 选中格子的行/列坐标 |
| `dword_755B10` | JVG 精灵对象 |
| `dword_755B14` | 文本/渲染上下文 |
| `dword_4E7CEC` | 当前 GXP 背景表面 |
| `word_755E7E` | 返回给脚本的结果 |
| `SMG.GRP/SMG.IDX` | 小游戏资源包 |

## 3. 类型 1：铁笼/方块机关

主函数：`sub_42AC40`

- 加载 `MG_WA.jvg/MG_WA.gxp`。
- 棋盘为 `5x4` 共 20 格，数据保存在 `unk_951378`，初始布局从 `unk_4EAB2C` 拷贝。
- 方块类型由 `dword_4EAB7C[]` 描述，至少包含单格、横向、纵向、2x2 等形状。
- 第一次点击选择方块，`sub_42B464` 计算合法落点并写入 `dword_951508[]`，第二次点击执行移动。
- 限时 `dword_95155C = 300` 秒；倒计时归零后返回失败，并设置 `word_951940 = -1`。
- 胜利条件是 `dword_9513AC == 2`。

关键函数：

```text
sub_42AC40  主循环/倒计时
sub_42AD14  初始化/加载资源
sub_42AED4  输入与渲染
sub_42B24C  选择方块
sub_42B464  计算可移动格子
sub_42C650  执行移动
```

## 4. 类型 2：八阵图

主函数：`sub_428DAC`

- `TKD.dat` 脚本注释直接写明 `{;八陣圖遊戲`。
- 上方有 8 个目标槽 `dword_4EA41C[8]`，下方是 `4x10` 共 40 格的工作区 `dword_4EA4DC[40]`。
- 点击槽位或工作区格子可选取/放置/交换；`sub_429AFC` 判断相邻关系。
- 胜利条件：8 个槽位必须正好等于：

```text
64, 37, 26, 28, 7, 39, 55, 52
```

关键函数：

```text
sub_428DAC  主循环
sub_428E24  加载 MG_EIGHT
sub_428F40  输入/放置/交换
sub_429AFC  邻接判定
sub_429A7C  放置到空位
sub_42983C  胜利判定
```

## 5. 类型 3：十八啦 / 骰子

主函数：`sub_429C20`

- 玩家和庄家各 3000 元。
- 三档下注，分别需要 0 / 500 / 1000 元。
- 每方掷 4 颗骰子，点数 `1..6`，随机源为 `sub_4B5A94() / 0x1555 + 1`。
- `sub_42A690` 根据四颗骰子计算点数，规则是“出现一对取另一对/散点组合，出现两对取较大的一对和”。
- 玩家赢：`dword_4EA910 += bet`，庄家扣款；庄家输光则玩家胜利。
- 玩家钱归零则失败。

关键函数：

```text
sub_429C20  主循环
sub_429C8C  加载 MG_eighteen
sub_429DA8  下注/动画/判定
sub_42A690  骰子点数计算
sub_42A5B0  骰子渲染
sub_42A588  资金胜负判定
sub_42ABD8  初始资金
```

## 6. 类型 4：珠子顺序

主函数：`sub_42DD88`

- 共 12 个槽位；左侧 6 个是目标区，右侧 6 个是待整理区。
- 点击右侧珠子会移到左侧第一个空位；点击左侧珠子会放回右侧并保持右侧顺序。
- 胜利条件：左侧 6 个槽位正好为：

```text
6, 5, 4, 3, 2, 1
```

关键函数：

```text
sub_42DD88  主循环
sub_42DE00  加载 MG_Ball
sub_42DF1C  输入
sub_42E22C  移动珠子
sub_42E37C  胜利判定
```

## 7. 类型 5：十六同数

主函数：`sub_42ED40`

- `4x4` 数字棋盘，数值为 `1..16`。
- 点击两个格子交换数字。
- 胜利条件：4 行、4 列、2 条对角线全部和为 34，即 10 条线全部成立。

关键函数：

```text
sub_42ED40  主循环
sub_42EDB8  加载 MG_44
sub_42EED4  输入
sub_42F268  选择/交换
sub_42F444  行/列/对角线判定
```

## 8. 类型 6：旋转拼图

主函数：`sub_42D3A4`

- `3x3` 棋盘，每格有“图案值”和“旋转方向”两个数据。
- 右键点击旋转当前格（方向 `0..3`）。
- 左键点击选择格子，再点另一格交换位置和方向。
- 胜利条件：所有格方向均为 `3`，且图案值匹配目标序列 `unk_4EAFC0`。

关键函数：

```text
sub_42D3A4  主循环
sub_42D41C  加载 MG_rotate
sub_42D538  输入/交换/旋转
sub_42DC10  胜利判定
```

## 9. 类型 7：龙蛇拼图

主函数：`sub_42E414`

- `4x4` 棋盘，值为 `1..32`。
- 点击格子会翻转自身及周围 5 个格子：值 `1..16` 与 `17..32` 互切。
- 胜利有两种目标：
  - 全部为 `1..16`：龙面，返回 `1`
  - 全部为 `17..32`：蛇面，返回 `2`
- 脚本中 `CheckResult(23,2)//翻出蛇` 和 `CheckResult(23,1)//翻出龍` 与返回值对应。

关键函数：

```text
sub_42E414  主循环
sub_42E48C  加载 MG_reverse
sub_42E5A8  输入
sub_42E96C  翻转逻辑
sub_42EB8C  龙/蛇两种胜利判定
```

## 10. 修改/复用建议

- 所有小游戏都通过 `sub_40E97C` 返回 `dword_951560`，所以脚本侧只需关心 `word_755E7E`。
- 资源文件固定为 `SMG.GRP/SMG.IDX`，内部条目名分别为 `MG_WA`、`MG_EIGHT`、`MG_eighteen`、`MG_Ball`、`MG_44`、`MG_rotate`、`MG_reverse`。
- 如果需要跳过小游戏，可在 `sub_40E97C` 入口注入 `dword_951560=1` 并直接写回结果，或在 `40EBD4.c` 的 `case 64` 处短路。
- 若要做编辑器，建议以每个小游戏的内存数组为“存档态”，而不是直接解析 GXP/JVG 图像。
