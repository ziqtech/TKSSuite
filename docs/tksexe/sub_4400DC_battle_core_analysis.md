## 3. 阶段划分

### 3.1 开场与技能 243-247 特判

地址范围：`0x4400DC - 0x44033A`

- 备份 `unk_9D6C50` 到 `byte_9D6C28`，共 40 字节。
- 清零 `word_9E028A`、`word_9E048C`，并 `memset(word_9D6FC6, 0, 0x40)`。
- 对 `word_9D6C7C`（当前技能/动作索引）做 243-247 特判：
  - 243：随机伤害倍率写入 `word_9D6C30`
  - 244：随机值生成 `word_9D6C3C`
  - 245：随机值映射到 `word_9D6C3E`
  - 246：随机值映射到 `word_9D6C3C/9D6C3E`
  - 247：写入 `word_9D6C38/9D6C3A` 的倍率

### 3.2 道具/治疗分支

地址范围：`0x44033A - 0x440914`

条件：`byte_9D6C4E & 2`

- 断言 `NowUseItem >= 0`。
- 遍历目标列表 `byte_9D6FA4[]`，数量为 `byte_9D6FC4`。
- 若 `word_77CBDA[NowUseItem<<6] > 0`，则给单位恢复：
  - 当前 HP `word_9D7084[]`
  - 上限 `word_9D708A[]`
  - 并调用 `sub_433F04` 写入恢复效果

### 3.3 主伤害/攻击阶段

地址范围：`0x440914 - 0x441DBA`

- `word_9D6C30` 为 HP 伤害值；`0` 表示无伤害。
- 若 `word_9D6C30 == 0xFFFF`，表示“按施法者面板计算”，从 `word_9D7092[attacker]` 取基础值。
- 随后进入伤害公式 switch：
  - `jpt_4409BF`：技能 45/52/101/102/103/105/106/107-131 等专用倍率
  - `jpt_4413CF`：目标类型/额外倍率
- 观察到多个公式片段：

```text
伤害 += (maxHP - curHP) * 伤害 * 2 / maxHP
伤害 += 伤害 * byte_9537D5 / 2
伤害 = 面板字段 * 系数
伤害 = 3000   // 技能 118
```

- 伤害过大会分级修正：`3000/2000/1000` 三档。
- 计算目标防御 `var_38`，再遍历 `byte_9D6FA4[]`。
- 伤害随机化：

```text
var_20 == 1:
    伤害 = random(var_28, var_24)
否则:
    伤害 = random(0, 伤害/2)
最低伤害 = 1
```

### 3.4 击杀、经验、金钱、掉落

地址范围：`0x441827 - 0x441B1B`

条件：`当前HP <= 伤害`，且攻击者为玩家方（`byte_9DF761[attacker] == 100`）、目标为敌方（`byte_9DF761[target] < 10`）。

- 统计击杀数 `word_9D7058++`。
- 技能 232/220 相关计数 `word_757F06/757F04`。
- 经验公式：

```text
exp = 当前HP * 等级 / 3 + 当前HP
exp = exp + exp / 2
累计到 dword_9D6F20[attacker]
同时累计到全局 dword_9D6F14
```

- JP 奖励：

```text
jp = word_9D7292[target] * 等级 / 3 + word_9D7292[target]
累计到 dword_9D6F18
```

- 金钱奖励：

```text
gold = word_9D7294[target] * 等级 / 3 + word_9D7294[target]
gold *= 2
累计到 arglist
```

- 掉落三槽：
  - 槽 1：`word_9D7296[target] > 0` 必定入队
  - 槽 2：`random(0,999) < 200`，即 20%
  - 槽 3：`random(0,999) < 50`，即 5%
  - 写入掉落队列 `word_9D6E12/9D6E14[]`，计数 `word_9D6F12`
- 最终 `word_9D7084[target] = 0`（置死）。

### 3.5 非致命伤害

地址范围：`0x441B1B - 0x441CA6`

- 直接 `word_9D7084[target] -= 伤害`。
- 若攻击者/目标满足阵营条件，追加伤害附带经验：

```text
附带经验 = 目标等级 * 伤害 / 3 + 伤害
附带经验 *= 2
累计到 dword_9D6F14
```

### 3.6 第二轮：MP/资源与范围结算

地址范围：`0x44225A - 0x4428EB`

- 使用 `word_9D6C3A` 作为 MP/资源伤害基础。
- 若超过 1000，额外修正 `var_1C`。
- 遍历目标列表：
  - 当前 MP：`word_9D7086[]`
  - 上限 MP：`word_9D708E[]`
  - 伤害写入 `word_9D7086[]`
- 对反应组 `word_9D70CC[] == 9` 的单位，通过 `sub_42F924` 在地图网格 `byte_951D42[]` 查找位置，再按 `unk_4EB782` 的偏移表扩散到周围单位。
- 每个效果调用 `sub_433F04` 入队。

### 3.7 最后状态/结果入队

地址范围：`0x4428FC - 0x442A91`

- 按 `word_9D6C7C` 分支随机生成状态掩码：
  - 技能 2：随机 1..5，写入 `word_9D6C3E`
  - 技能 3：随机 0..4，写入 `word_9D6C3C`
  - 技能 122：随机 5..11，写入 `word_9D6C3C` 并给目标 `word_9DF7C2[] |= 0x1000`
- 累加 `word_9DF6BA[target]`。
- 调用 `sub_434080` 将 `arg_0/目标/9D6C3C/9D6C3E/9D6C40/9D6C42/标志` 写入结果队列。
- 尾段恢复 `byte_9D6C28 <- unk_9D6C50` 后返回。

## 5. 结论

`sub_4400DC` 实际是“单次战斗动作执行器”：

```text
技能特判 -> 道具/治疗 -> 伤害公式 -> 击杀/经验/掉落 -> 资源/范围结算 -> 状态/结果入队
```

它不是单纯的伤害函数，而是把伤害、经验、金钱、掉落、状态、特效队列全部聚合在一起的战斗结算中枢。
