# 方向编号与映射

> 覆盖地图 8 方向 `sub_4075C0` 与战斗 4 方向 `sub_449F84` 的编号算法。

## 1. 地图 8 方向

`sub_4075C0` 根据坐标差返回 1-8：

| 编号 | 方位 |
| --- | --- |
| 1 | 上 |
| 2 | 右上 |
| 3 | 右 |
| 4 | 右下 |
| 5 | 下 |
| 6 | 左下 |
| 7 | 左 |
| 8 | 左上 |

对角判定阈值为 `3 * |短边| >= |长边|`。

## 2. 战斗 4 方向

`sub_449F84` 以 `target - current` 的 delta 分类：

| 判定 | 方向 |
| --- | --- |
| dx > 0, dy > 0 | 0 |
| dx <= 0, dy > 0 | 1 |
| dx <= 0, dy <= 0 | 2 |
| dx > 0, dy <= 0 | 3 |

更竖直时只区分 dy 正负，更水平时按 dx/dy 象限分类。

## 3. TKAct 方向组

用 `sub_4075C0` 的 8 方向输出与 `sub_449F84` 的 4 方向输出交叉验证：

| 4 方向 | 覆盖的 8 方向 | 方位组 |
| --- | --- | --- |
| 0 | 4、5、6 | 下向组：右下 / 下 / 左下 |
| 1 | 6、7、8 | 左向组：左下 / 左 / 左上 |
| 2 | 1、2、8 | 上向组：上 / 右上 / 左上 |
| 3 | 2、3、4 | 右向组：右上 / 右 / 右下 |

因此 `byte_9DF446` 的 0-3 是四象限方向组，而不是单一对角线编号。
