## 一、结论

孝谈三国3终极版 `TKS.exe` 与原版 `TKS.exe` 的差异不是简单的 IAT Hook，也不是只启动一个外部程序。

确认结果：

- `.text` 中有 65 个连续改动区，共 517 个差异字节。
- 其中 25 个差异区以长跳转进入 `.test`。
- `.test` 一共有 30 个 cave 入口，因为部分差异区同时包含两个入口。
- `.data` 有 4 个差异区，共 26 个字节。
- `.rsrc` 有 1 个差异区，共 4 个字节。
- 新增 PE 节区：`.test`、`.Newdata`、`.Silvana`。
- 新增导入：`WinExec`、`ShellExecuteA`。
- 修改重点包括战斗伤害公式、行动值、状态、经验、掉落、脚本判定和召唤目标。

## 三、为什么早期“IAT Hook”结论是错的

早期分析把 `.text` 中的相对跳转误判为 IAT 劫持。实际指令形态是：

```asm
E9 xx xx xx xx    ; 近跳转到 .test 或 .text 内的 cave
```

这些修改的目标包括：

- `.test` 新增可执行节。
- `.text` 原有零填充区域。
- `.data` 中的一段重复注入。

它们不是通过导入地址表改写函数地址。

`.Silvana` 虽然确实重建了导入表，但新增导入只有：

- `WinExec`
- `ShellExecuteA`

不能据此推导出“34 个 IAT Hook”。

## 五、伴随程序机制

`.Newdata` 中的主要字符串：

```text
YinShiXing2013
system.exe
closesystem.exe
吾爱破解.exe
open

亲,请把辅助程序放在游戏目录下!!!
游戏无法执行!!!
未检测到辅助程序运行!!!游戏退出!!!
抱歉,出错了!
```

实际控制流：

| 项目 | 结论 |
|---|---|
| `FindWindowExA("YinShiXing2013")` | 会被调用 |
| 检测失败后的 `MessageBoxA` | 不可达死代码 |
| 检测失败后的 `ExitProcess` | 不可达死代码 |
| `ShellExecuteA("closesystem.exe")` | 窗体关闭时会尝试执行 |
| `WinExec` | 已导入，但未发现有效调用 |
| 辅助程序文件缺失是否导致游戏退出 | 不会 |

因此这部分对玩家基本没有实际影响，属于残留的伴随程序框架。

## 七、战斗和奖励的典型改动

- 技能 106 `紫破 → 眾橫亂斬`：倍率 16 → 18。
- 技能 118 `騰龍八齊`：固定伤害 3000 → 1800。
- 技能 128 `斷頭斬 → 斷陽殘虹`：等级缩放除数 3 → 2。
- 技能 131 `俠義一擊 → 萬夫莫敵`：高比例爆发倍率大幅降低。
- 技能 114 `鳳舞九天`：额外增加“当前攻击 / 4”。
- 燃烧与冰冻的回合百分比除数改为 65535，几乎不再扣血/掉内力。
- 破兵状态的错误 `-300%` 惩罚修正为 `-30%`。
- 防御时会错误写入 `0x7530`，导致发光 BUG。
- 第二、第三掉落槽由 20%/5% 改为必定成功。
- 死亡队员也会进入经验/JP分配。
- 单次经验上限由 30000 提高到 59910。
