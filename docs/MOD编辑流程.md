# TKSWarpcEditor 战场人物编辑器

## 核心数据结构

- **图片关联**：`Fa.jvg`、`Awt.jvg`、`Awk.jvg`、`Mu.jvg`
- **原版数据文件名**：`WarPC.dat`（War Player Character 的缩写）

| 数据项 | 设置位置 | 对应关系 |
| ------ | -------- | -------- |
| 人物名称 | 核心属性标签 - 名称 | TKT ID |
| 战斗头像 | 核心属性标签 - 头像索引 | `Fa.jvg` 中的序号除以 2 |
| 战斗待机 | 装备与技能标签 - 战场图集索引（补丁专用） | `Awk.jvg` 与 `Awt.jvg` 中的序号，两者需一致 |
| 队伍头像 ID | 装备与技能标签 - 历史文本ID（补丁专用） | `Mu.jvg` 中的全局帧序号（左下角选中帧信息显示的全局第几帧） |
| 地图实体 ID | 装备与技能标签 - 地图实体ID | 对应 TKSMatEditor 编辑器中角色的实体ID；设置后角色才能关联到剧情里，入队离队才能正常 |
| 人物历史 | 装备与技能标签 - 历史文本ID（补丁专用） | 对应菜单中的角色历史 TKT ID |

## 其它问题

### 1. Cha.jvg 在哪里设置？

`Cha.jvg` 仅在 TKSMatEditor 的实体上设置。

### 2. TKAct.dat 设置了新技能动画如何生效？

技能动画仅在 `TKKon.dat` 中关联到技能效果。使用 TKSKonEditor 编辑器设置技能效果时，设置 TKAct 动画索引。

### 3. 角色新的攻击动画怎么关联到 WarPC.dat？

1. 在 TKSKonEditor 中设定 TKAct 动画索引，即给技能判定效果设置技能动画。
2. 在 TKSWarpcEditor 的技能效果判定中设置 TKSKon 索引，即设定角色的技能使用哪一个技能效果。

### 4. 为什么设置这么麻烦？

原版游戏数据结构就是如此。
