## 一、开始之前：三种发行包怎么选

本套件提供三种打包版本，按你的需求选一种即可：

| 发行包 | 适合谁 | 包含内容 |
|---|---|---|
| **TKSLauncher 玩家精简包** | 只想玩游戏、用别人做好的 MOD 的普通玩家（**推荐大多数人用这个**） | TKSLauncher.exe（启动器）、TKSConfigsEditor.exe（配置编辑器）、TKSSaveEditor.exe（存档编辑器） |
| **TKSEditors 完整包** | 想自己制作 MOD、修改游戏数据的进阶玩家 | 全部 18 个程序 |
| **Winlator 手机包** | 在安卓手机上通过 Winlator 玩的玩家 | TKSLauncherCLI.exe（命令行启动器）+ 配置文件 |

**安装方法：** 把发行包解压到任意文件夹即可，不需要安装。注意：

- 包内的 `libs/`、`configs/`、`tools/`、`mods/` 文件夹和 `tks_patches.json`、`launcher_config.json` 是程序运行必需的，**不要删除、不要移动**，保持和 exe 在同一目录。
- 发行包**不包含游戏本体**。你需要自己准备《孝谈三国3终极版》游戏目录（里面有 `TKS.exe`、`TKT.dat`、`TKItem.dat` 等文件）。
- 编辑器套件可以放在任意位置，不必放进游戏目录。

## 二、最重要的三条安全守则

1. **改任何东西之前，先备份整个游戏目录**（复制一份放到别处）。虽然大部分编辑器保存时会自动生成 `.bak` 备份文件，但完整备份永远是最保险的。
2. **优先用 MOD 方式，少直接改游戏文件。** 编辑器都支持把修改"导出为 MOD（.tksmod）"，MOD 由启动器在游戏启动时临时应用、退出后自动还原原始文件，随时可以关掉，不会弄脏游戏目录。直接保存则会覆盖游戏原文件（有 `.bak` 兜底）。
3. **一次只改一点，改完就进游戏试。** 如果一次改了几十处，出问题时你不知道是哪处引起的。

## 三、通用操作说明（所有编辑器都一样）

所有数据类编辑器（物品/武将/技能/商店/战斗效果等）的界面和操作方式高度一致：

### 3.1 打开数据

菜单 **文件 → 加载 TKS 目录…**（快捷键 `Ctrl+O`），然后选择你的**游戏目录**（就是 TKS.exe 所在的那个文件夹）。编辑器会自动找到需要的数据文件（如 TKItem.dat、TKT.dat 等），并把物品名、技能名、图标等一起显示出来。

窗口底部会显示各个数据文件是否加载成功，如显示"未加载"，说明游戏目录里缺该文件。

### 3.2 界面布局

- **左侧列表**：全部记录（物品/角色/技能……），点一行就选中一条。
- **右侧"检查器"面板**：显示选中记录的所有属性，可直接修改。
- **顶部工具栏**：搜索框（输入名字或编号回车即可）、分类过滤下拉框、"重新加载"按钮、"切换主题"按钮。
- 修改完一条记录后，记得点右侧的 **"✅ 应用"** 按钮，修改才会写进内存；点"🔄 重置"可放弃本条的修改。

### 3.3 保存

- **文件 → 保存**（`Ctrl+S`）：直接覆盖游戏目录里的原文件，同时自动生成 `原文件名.bak` 备份。想恢复原样时，删掉被改的文件、把 `.bak` 改回原名即可。
- **文件 → 导出为 MOD (.tksmod)…**：把你的修改和原始数据的"差异"打包成一个 `.tksmod` 文件（会让你填写 MOD 名称、作者、版本、说明）。不动游戏文件，推荐用这种方式。
- **文件 → 导入 MOD (.tksmod)…**：把别人做的 MOD 读进编辑器查看/继续修改。

### 3.4 帮助

每个编辑器的菜单栏都有 **帮助 → 帮助说明**，里面有该编辑器的详细字段解释，遇到不懂的字段可以先看这里。

## 四、TKSLauncher — 游戏启动器（必读）

**这是整个套件中最核心的程序。** 平时玩游戏请用它启动，而不是直接双击 TKS.exe。

### 4.1 它能干什么

1. **应用修复补丁**：游戏原版有很多 BUG（经验溢出、死战自我攻击、回车键误用物品等），启动器在游戏启动瞬间将修复补丁打进游戏内存——**不修改 TKS.exe 文件本身**，退出游戏后什么痕迹都不留。
2. **加载 MOD**：自动加载 `mods/` 文件夹里的 `.tksmod` / `.tksmodpak` 文件，游戏退出后自动还原原始文件。
3. **MOD 工具箱**：打包/合并/拆分/编辑 MOD，不需要会任何技术。
4. **一键生成 MOD**：自定义头像、自定义音乐，上传图片/音频就能生成 MOD。
5. **存档管理**：一键备份/恢复游戏存档（连同当时的补丁/MOD 勾选状态一起快照）。
6. **注入辅助工具**：如 cnc-ddraw 画面增强（窗口化/拉伸/滤镜），退出后自动清理。
7. **数据扩容**：如果 MOD 增加了新物品、新角色、新技能，启动器会自动让游戏支持扩容后的数据（原版有硬编码上限）。

### 4.2 界面总览（三栏布局）

主窗口从左到右分三栏，顶部是一排工具按钮：

| 区域 | 内容 |
|---|---|
| **左栏：补丁列表** | 全部补丁。必选补丁灰显且始终启用；可选补丁逐个勾选，表头复选框可**全选/全不选**，鼠标悬停可看每个补丁的详细说明 |
| **中栏：模组列表 + 模组信息** | 上半是 `mods/` 文件夹里扫描到的全部 MOD（勾选 = 启用）；点选某个 MOD，下半显示它的名称/作者/版本/描述/预览图 |
| **右栏：启动日志 + 辅助工具** | 上半是启动过程的实时日志（出问题时看这里报什么错）；下半是辅助工具单选面板（见 4.5） |

两个好用的细节：

- **勾选状态自动记忆**：补丁/模组/辅助工具的勾选会自动保存到同目录的 `launcher_setting.json`，下次打开自动恢复，不用每次重勾。
- **重复 ID 拦截**：如果 mods 文件夹里有两个 MOD 的 ID 相同，状态栏会显示"❌ 存在重复ID"并禁用启动按钮，删掉或用"模组信息编辑"改掉其中一个的 ID 即可恢复。

### 4.3 快速上手（日常启动流程）

1. 双击 `TKSLauncher.exe`。
2. 勾选想要的可选补丁（见 4.6 清单；不确定就保持默认）。
3. 想用 MOD 就把 `.tksmod` / `.tksmodpak` 放进 `mods/` 文件夹，在模组列表勾选启用。
4. （可选）在右下角选一个辅助工具。
5. 点 **🚀 启动并注入**，在弹出的文件对话框里选择你的 `TKS.exe`。
6. 游戏窗口出现后，启动器会在游戏窗口上显示一个小悬浮标签提示补丁状态，工具栏显示"✅ 补丁已生效"即成功。
7. **正常退出游戏**（不要强杀进程），启动器会自动还原被 MOD/辅助工具替换过的文件。

### 4.4 工具栏按钮逐个说明

顶部工具栏从左到右共 10 个按钮（菜单 **文件(F)** 里有相同入口，外加一项菜单独有的"打包 TKS.exe 为 MOD"）：

#### 🚀 启动并注入（Ctrl+Enter）

核心按钮。选择 TKS.exe 后自动完成：存档健康检查 → 应用启用的 MOD → 注入辅助工具 → 启动游戏 → 打入勾选的补丁 → 后台监控直到游戏退出 → 还原文件。全程进度在右侧"启动日志"中可见。

#### 📦 模组打包

把**多个 `.tksmod` 打包成一个 `.tksmodpak` 合集文件**（只是装进一个包里，各 MOD 保持独立，适合整合分享系列 MOD）。对话框内按钮：

| 按钮 | 作用 |
|---|---|
| 添加文件… | 选择若干 `.tksmod` 加入打包列表 |
| 从目录添加… | 选一个文件夹，把里面的 `.tksmod` 全部加入 |
| 移除选中 / 清空 | 从列表剔除文件 |
| 重新生成 | 随机生成一个新的合集 ID（避免和别人的包撞 ID） |
| 选择图片… / 清除 | 给合集设置/去掉预览封面图 |
| 浏览… | 选择输出位置和文件名 |
| 📦 执行打包 | 生成 `.tksmodpak` |

同时可填写合集名称、作者、版本、描述等信息。

#### 🔗 模组合并

把**多个 `.tksmod` 深度合并成单个 `.tksmod`**。与"打包"的区别：打包只是装盒子，合并则是把内容揉在一起——同一个游戏文件的不同帧/不同记录会逐条合并（例如 A 改了张飞、B 改了赵云，合并后一个 MOD 同时包含两处修改）。按钮与打包对话框基本相同（添加文件… / 从目录添加… / 移除选中 / 清空 / 重新生成 ID / 选择预览图 / 浏览输出 / 🔗 执行合并），额外多一个**合并预览树**：列出合并后每个目标文件来自哪些 MOD，多个 MOD 改到同一处（有重叠）时会高亮提醒——重叠处按列表顺序后者覆盖前者，添加顺序很重要。

使用场景：多个小 MOD 想简化成一个；或两个 MOD 冲突时手动控制合并结果。

#### 📂 模组拆分

与打包相反：从 `.tksmodpak` 合集中**把原始的 `.tksmod` 提取出来**。按钮：**打开…**（选合集文件，下方预览列表显示包内容）→ **浏览…**（选提取到哪个文件夹）→ **📂 执行拆分**。

#### 🔧 模组编辑

直接**编辑一个 `.tksmod` / `.tksmodpak` 的内部文件**（不需要重新制作整个 MOD）。先在模组列表选中某个 MOD 再点此按钮会自动加载它。按钮：

| 按钮 | 作用 |
|---|---|
| 打开… | 选择要编辑的 MOD 文件，列出内部全部文件 |
| ➕ 添加文件… | 往 MOD 里塞新文件（如补一张图、加一个数据文件） |
| 🗑 删除选中 | 删掉 MOD 里的某个内部文件 |
| 💾 保存 | 原地保存回原文件 |

#### ✏️ 模组信息编辑

只改 MOD 的**元数据**（ID、名称、作者、版本、描述、加载顺序、预览图），**不动模组内容**。两个 MOD ID 冲突时就用它改其中一个的 ID。同样支持先在列表选中再打开。

#### 🖼️ 自定义头像

**不懂任何修图也能换头像**：选择要替换头像的角色 → **📁 上传图片**（任意 PNG/JPG）→ 在预览框里拖动/缩放裁剪 → **✅ 确定生成**。启动器会自动完成尺寸/颜色转换并生成一个头像 MOD 放进 `mods/`，勾选启用即可。搭配可选补丁"禁止 PFace.jvg 生效"和"读档后自定义形象保护"效果最稳。

#### 🎵 自定义音乐

管理游戏 BGM（Sound 目录曲目）并生成音乐 MOD：

| 按钮 | 作用 |
|---|---|
| 浏览… / 重新扫描 | 指定游戏的 Sound 目录并扫描曲目列表 |
| 播放 / 暂停 / 重置 | 试听选中曲目 |
| 修改 | 选一个 `.mp3` 覆盖该曲目（换掉某首 BGM） |
| ➕ 新增音效 | 添加全新曲目（自动编号，文件名是数字时保留原编号） |
| 重命名 | 修改新增曲目的编号 |
| 删除 | 移除新增曲目，或清空对原版曲目的修改（变回未修改） |
| 📤 导出为 .tksmod | 把全部修改打包成音乐 MOD |
| 📥 导入 .tksmod | 读入别人的音乐 MOD 继续编辑 |

#### 💾 存档管理

备份/恢复游戏存档。特别之处：每份备份除了存档文件，还会记录**当时的补丁/模组/辅助工具勾选状态**，恢复时一并还原——因为某些存档（如启用扩容 MOD 时建的档）必须搭配同样的 MOD 环境才能正常读取。按钮：

| 按钮 | 作用 |
|---|---|
| 浏览… | 指定游戏目录（启动过一次游戏后会自动记住） |
| 💾 创建备份 | 输入备份名，把当前存档 + 勾选状态快照存为一份备份 |
| 📦 恢复选中备份 | 把选中的备份写回游戏存档，并恢复当时的勾选状态（游戏运行中时会拒绝操作） |
| 🗑️ 删除选中备份 / 🔄 刷新列表 | 管理备份列表 |

#### 🌗 切换主题（Ctrl+T）

深色/浅色界面切换。

#### 菜单独有：打包 TKS.exe 为 MOD…（文件菜单）

把一个**第三方修改版 TKS.exe** 打包成特殊类型的 `.tksmod`：启用后启动游戏时自动用它替换原版 TKS.exe，游戏退出后自动换回原版——让你在"原版"和"第三方整合版"之间无痛切换，不用手动换文件。

### 4.5 辅助工具面板（使用 / 添加 / 删除）

右下角的"辅助工具"面板用于在启动游戏时向游戏目录**临时注入一套额外文件**（最典型的是画面增强用的 ddraw.dll）。

**内置两个工具：**

| 工具 | 作用 |
|---|---|
| **cnc-ddraw** | 知名的老游戏画面增强库：窗口化、自由拉伸、高分辨率缩放、多种画面滤镜（双线性/锐化/扫描线/xBR/xBRZ 等 Shader）。注入后可在游戏目录双击 `cnc-ddraw config.exe` 打开图形化设置面板调整（或直接改 `ddraw.ini`） |
| **ddraw** | 精简版 ddraw 兼容层，只有一个 dll，解决新系统上的基本兼容问题 |

**怎么使用：**

1. 在面板里点选一个工具（单选，选"**无**"表示不注入），选择会自动记忆。
2. 点"启动并注入"。启动器会把该工具文件夹里的**全部文件复制进游戏目录**（日志会逐个列出）。如果游戏目录已有同名文件，会先备份为 `.toolbak` 再覆盖。
3. **游戏退出后自动清理**：新复制的文件全部删除、被覆盖的文件从 `.toolbak` 还原——游戏目录保持干净，不想用了选回"无"即可，无需手动卸载。

**怎么添加自己的工具：**

1. 打开启动器目录下的 `tools/` 文件夹。
2. 新建一个子文件夹（文件夹名 = 面板上显示的工具名），把要注入游戏目录的文件放进去（支持子目录，目录结构会原样复制到游戏目录）。
3. 重启启动器，面板上就会多出这个选项。

   例：想加一个叫"我的高清补丁"的工具 → 建 `tools/我的高清补丁/`，把 dll/配置文件放进去即可。

**怎么删除工具：**

直接删掉（或移走）`tools/` 下对应的子文件夹，重启启动器后该选项消失。删除前确保没有正在运行的游戏在用它；若之前选中的工具被删除，启动器会自动回退到"无"。

### 4.6 可选补丁清单（按用途分类）

以下补丁按需勾选，不确定就保持默认：

**BUG 修复类（建议全部开启）**

| 补丁 | 作用 |
|---|---|
| 武器附加状态修复 | 修复反击/连击时武器附加异常状态误触发的问题 |
| 死战自我攻击修复 | 修复死战状态下使用物品后攻击自己致死的 BUG |
| 死战反击自伤修复 | 修复死战状态下反击打到自己的 BUG |

## 五、TKSLauncherCLI — 命令行启动器（手机/安卓玩家）

这是 TKSLauncher 的**无界面版本**，专为安卓手机上的 Winlator（Wine 模拟器）设计，功能与 GUI 版一致（打补丁、加载 MOD、启动游戏），只是没有窗口，全部通过配置文件控制。

### 5.1 手机部署步骤

1. 在电脑上把 **Winlator 发行包**（`TKSLauncherCLI.exe`、`launcher_config.json`、`tks_patches.json`、`configs/`、`mods/`）全部复制进手机上的**游戏目录**（和 TKS.exe 放一起）。
2. 用文本编辑器打开 `launcher_config.json`，按里面的中文注释修改：
   - `patches.enabled`：想启用哪些可选补丁就把补丁 ID 写进这个列表（文件里已附每个 ID 的中文说明）。
   - `mods.enabled_ids`：留空 `[]` 表示启用 mods 文件夹里的全部 MOD。
   - `advanced.no_suspend`：**手机上必须保持 `true`**。
3. 想用 MOD 就把 `.tksmod` 文件放进 `mods/` 文件夹。
4. 在 Winlator 中运行 `TKSLauncherCLI.exe`（而不是 TKS.exe），它会自动完成打补丁并拉起游戏。

### 5.2 常用命令行参数（电脑上调试用）

```
TKSLauncherCLI.exe                              直接启动（读同目录配置）
TKSLauncherCLI.exe --tks-exe "D:\game\TKS.exe"  指定游戏路径
TKSLauncherCLI.exe --no-mods                    本次不加载 MOD
TKSLauncherCLI.exe --timeout 60                 等待游戏就绪 60 秒
```

出问题时可加 `--no-runtime-hooks`、`--no-watchdog` 等诊断参数逐步排查（详见 `launcher_config.json` 内注释）。

## 六、TKSSaveEditor — 存档编辑器

**修改游戏存档**：金钱、队伍、物品、属性、剧情进度等。

### 6.1 使用步骤

1. 双击 `TKSSaveEditor.exe`。
2. **文件 → 📂 打开存档目录…**，选择**游戏目录**（编辑器会自动找到其中的 `save` 存档文件夹和数据文件）。
3. 工具栏上有 **1~9 九个槽位按钮**，对应游戏内 9 个存档位，点击切换要编辑的存档。
4. 修改后 **💾 保存当前槽位**（`Ctrl+S`）。

### 6.2 各标签页功能

| 标签页 | 能改什么 |
|---|---|
| **总览** | 金钱、游戏时间、当前场景、队伍预览 |
| **队伍** | 6 个队伍成员是谁、各自等级 |
| **背包** | 全部物品：物品种类、数量（可视化列表带图标，直接加东西、改数量） |
| **事件** | 剧情开关、事件变量、事件标志——**控制剧情进度的核心数据，慎改**（乱改可能导致剧情卡死） |
| **全局** | 当前地图、主角姓名、智慧/仁德/勇气/医术、战斗统计（胜场/杀敌数）、收纳灵魂/兽元等 |

### 6.3 安全机制

- 保存时自动备份原存档为 `.bak`，改坏了删掉新文件、把 `.bak` 改回原名即可恢复。
- 保存后编辑器会自动"回读验证"，确保写入的数据完好，验证不过会报错并保留原文件。
- **建议：** 编辑存档前先在游戏里存个新档专门用来试验。

> 存档里还藏着**角色养成数据**和**地图实体状态**，分别由武将编辑器和地图编辑器的"存档模式"负责——三个工具的分工和完整改档流程见 [第二十三章：修改存档说明](#二十三修改存档说明三个编辑器联动指南)。

## 七、TKSConfigsEditor — 配置编辑器

配合启动器的"自定义玩法类"补丁使用，用可视化界面编辑 `configs/` 文件夹里的配置文件。**改完这里的配置后，还要在启动器里勾选对应补丁才会生效。**

### 7.1 使用步骤

1. 双击 `TKSConfigsEditor.exe`，它会自动加载同目录 `configs/` 下的配置。
2. （可选）点 **📂 加载TKS目录** 选择游戏目录——这样"召唤表"等面板能显示角色名字和头像，而不是干巴巴的编号。
3. 在各标签页修改后，点 **💾 保存**。
4. 下次用启动器启动游戏时（勾选了对应补丁）即生效。

### 7.2 六个配置面板

| 面板 | 功能 | 对应启动器补丁 |
|---|---|---|
| **掉落概率** | 调整战斗死亡掉落中"普通槽"和"稀有槽"的掉落百分比（常规槽固定 100% 不可改） | 物品掉落概率自定义 |
| **装备类型标签** | 自定义装备类型的显示名称（影响各编辑器里的权限选项文字） | —（编辑器共用） |
| **召唤表** | 修改每个召唤技能召唤出来的角色，部分技能支持"从多个角色中随机" | 召唤角色自定义 |
| **字体配置** | 设置游戏界面默认使用哪个字体区段 | 游戏默认字体自定义 |
| **动画速度** | 状态/攻击/移动/技能 4 类战斗动画分别调速 | 战斗动画速度自定义 |
| **经验锁定** | 勾选要"压级"的队伍槽位（该槽位战斗胜利不获得经验、不升级） | 战斗经验锁定（压级） |

### 7.3 分享配置

**文件 → 导出为 MOD (.tksmod)…** 可以把"召唤表"和"掉落概率"两项配置打包成 MOD 分享给别人（其他配置项不支持打包，属于本机设置）。

## 八、TKSItemEditor — 物品编辑器

编辑游戏全部 **600 件物品**（药品、道具、武器、防具、饰品、特殊物品）的数据文件 `TKItem.dat`。

### 8.1 能改什么

- **基础**：物品名称、说明文字（关联文本库）、图标、价格、所属商店分页。
- **数值效果**：使用/装备后增加的生命、内力、攻击、防御、命中、闪避、速度、幸运、悟性、移动、技能点、医术。
- **使用权限**：哪些角色能用（按武器类型：刀/剑/枪/矛/弓/大刀/戟/锤；按场合：战斗中/非战斗）。
- **技能关联**：装备后附加被动效果、装备/使用后学会技能（例如做一本"用了就学会某技能"的秘籍）。
- **状态效果**：攻击命中时给敌人附加异常状态（中毒、定身、迷恋……）、使用时解除哪些异常状态。
- **特殊效果**：战后经验×2、JP×2、遇敌率降低、免遇敌等戒指类特效。

### 8.2 界面与操作

左侧物品列表（带图标、名称、价格），支持按名称搜索、按分页（药品/道具/武器/防具/饰品/特殊）和权限过滤。右侧检查器逐项修改，每个输入框都有悬浮提示解释该字段含义。

- **编辑 → 新建物品**：游戏预留了 40 个空槽（#560~#599），可以创建全新物品。
- **复制到空槽**：以现有物品为模板做新物品，最方便。
- 修改物品名称/说明文字需要用文本选择器（点字段旁的按钮），从文本库中选择或先用 TKSTktEditor 新增文本。

### 8.3 注意

- 保存直接写 `TKItem.dat`（自动 `.bak` 备份）；推荐"导出为 MOD"分享。
- "装备后学习技能"字段只能**升级**角色已会的技能，不能从零教会；"使用后学习技能"才能教会新技能。

## 九、TKSWarpcEditor — 武将（角色）编辑器

### 9.1 五个标签页

| **装备与技能** | 4 个装备槽、装备技能、被动技能、使用权限（能用什么武器防具）、战后奖励（JP/金钱）、**掉落物品**（必掉/20% 概率/5% 概率三个槽） |

| **全部字段** | 原始数据网格（给高级用户兜底用） |

### 9.2 特色功能

### 9.3 玩家常用场景

## 十一、TKSShopEditor — 商店编辑器

## 十二、TKSKonEditor — 战斗效果编辑器

编辑 **650 条战斗效果记录**的数据文件 `TKKon.dat`。

### 12.1 这是什么

游戏里"在战斗中使用某个物品/技能会发生什么"（伤害多少、什么范围、放什么特效动画、播什么音效）是由 TKKon 记录定义的。物品 → TKKon → 动画（TKAct），三者串起来才是完整的战斗表现。

### 12.2 能改什么

- 目标范围、伤害数值/伤害公式（固定值、百分比、按攻击力计算等，帮助菜单里有编码规则说明）。
- 附加的异常状态。
- 关联的特效动画编号和音效。

### 12.3 适合谁

主要面向 MOD 制作者。普通玩家如果只是想"让某个药回血更多"，去物品编辑器改"恢复生命"字段就够了；只有想改**战斗中使用时**的效果/演出，才需要这里。

## 十三、TKSMatEditor — 地图实体编辑器

编辑数据文件 `TKMat.Dat`（**6000 个地图实体**）——游戏里每张地图上的 NPC、传送点、宝箱、机关、随机遇敌区、剧情触发器，全在这里。**这是最复杂的编辑器，属于 MOD 制作向工具。**

### 13.1 能干什么

- **可视化场景画布**：直接看到某张地图上所有实体的位置，点选编辑。
- **实体编辑**：位置坐标、朝向、动画、碰撞范围、渲染层级。
- **传送点**：改传送目的地（哪张图、哪个坐标、什么朝向）。
- **随机遇敌区**：改遇敌的战斗编号、概率、冷却时间、是否跟随队伍等级。
- **NPC**：立绘、行走动画、寻路。
- **剧情脚本**：内置脚本编辑器，可以查看和修改实体挂载的剧情脚本（对话、给物品、开关门等）。
- **存档模式**：可直接编辑存档里的实体状态（例如把已开过的宝箱重置）。详见 [第二十三章：修改存档说明](#二十三修改存档说明三个编辑器联动指南)。

### 13.2 玩家常用场景

- 改传送点，做"任意门"。
- 关掉某片区域的随机遇敌。
- 跳过卡住的剧情（修改剧情标志/脚本，请先阅读编辑器内帮助）。

### 13.3 注意

牵一发动全身，剧情脚本乱改容易导致主线卡死。**务必用 MOD 导出方式或提前备份**，并只在测试存档上验证。

## 十四、TKSWardataEditor — 战场编辑器

编辑 **219 场战斗**的配置文件 `WarData.dat` 和 100 张战场地图的通行数据 `WarWay.dat`。

### 14.1 能改什么

- **敌人配置**：每场战斗最多 18 个敌人——是谁（选 WarPC 角色）、等级范围、站位坐标、朝向、精英标记、属性加成倍率。

### 14.2 玩家常用场景

- 调难度：改敌人等级、数量、加成倍率。
- 改战场宝箱掉落。
- 自制挑战战斗。

## 二十一、TKSFontEditor — 字体编辑器

## 二十二、MOD 是什么？怎么安装、怎么制作？

### 22.1 两种 MOD 文件

- **`.tksmod`**：单个 MOD，内含对游戏数据的修改差异和/或替换资源。
- **`.tksmodpak`**：MOD 合集包，内含多个 .tksmod。

### 22.2 安装别人的 MOD（超简单）

1. 把 `.tksmod` / `.tksmodpak` 文件放进启动器目录下的 **`mods/` 文件夹**。
2. 打开 TKSLauncher，在 MOD 列表勾选启用。
3. 启动游戏。启动器会自动备份原文件 → 应用 MOD → 游戏退出后还原。

启动器会自动检测 MOD 之间的依赖和冲突并给出提示。冲突时后加载的覆盖先加载的，可以调整加载顺序。

### 22.3 制作自己的 MOD

1. 用对应的编辑器（物品/武将/技能/商店/文本/图集……）打开**原版游戏目录**，做出你想要的修改。
2. **不要点保存**，而是选 **文件 → 导出为 MOD (.tksmod)…**。
3. 填写 MOD 名称、作者、版本、描述。
4. 得到一个 `.tksmod` 文件，自己用就放进 `mods/`，分享就发给别人。

> 小技巧：如果你已经把修改直接保存进了游戏文件，仍然可以用"**导出为 MOD（指定参考目录）**"功能——指定一份原版游戏目录做对比，编辑器会自动算出差异打包成 MOD。

## 二十三、修改存档说明（三个编辑器联动指南）

很多玩家最想做的事就是"改存档"。需要知道的第一件事是：**游戏存档里不止有金钱和背包，还完整保存了全部角色的养成数据和每张地图的实体状态**。因此改存档一共涉及**三个编辑器**，各管一块，本章把它们放在一起讲清楚。

### 23.1 存档文件里有什么

每个存档槽位（1~9）由游戏目录下的两个文件组成：

| 文件 | 内容 |
|---|---|
| `save\sav.N` | 存档正文，内部分三大块：**① 地图实体表**（每张地图上 NPC/宝箱/机关/触发器的当前状态）、**② 全局数据**（金钱、队伍、背包、剧情事件、统计）、**③ 全部角色数据**（143+ 名角色进入存档时刻的等级/属性/技能/装备快照） |
| `N.sav` | 存档索引（读档界面显示用）：队伍成员、金钱、时间戳、等级、场景 |

三大块分别对应三个编辑器：

| 想改的内容 | 用哪个编辑器 | 怎么进入存档编辑 |
|---|---|---|
| 金钱、队伍、背包、剧情进度、全局状态 | **TKSSaveEditor** | 它天生就是改存档的：**文件 → 打开存档目录…** → 选槽位 |
| 角色的等级/属性/技能/装备（改"已练成"的角色） | **TKSWarpcEditor** | **文件 → 加载存档 (从游戏目录)…** → 选槽位（存档模式） |
| 地图上的实体状态（宝箱、机关、NPC、剧情触发器） | **TKSMatEditor** | 菜单中的**加载存档 / 存档模式** → 选槽位 |

> 区分一个关键概念：直接"加载 TKS 目录"改的是 `WarPC.dat` / `TKMat.Dat` 等**初始数据**，只对**新开局**生效；想影响**已经在玩的进度**，必须走上表的**存档模式**。

### 23.2 TKSSaveEditor 能改的部分（全局数据 + 索引）

- **总览**：金钱、游戏时间、当前场景、队伍预览。
- **队伍**：6 个队伍成员是谁、各自等级（同时更新读档界面显示的 `N.sav` 索引）。
- **背包**：全部物品的种类和堆叠数量，带图标可视化编辑，可直接添加任意物品。
- **事件**：剧情开关（32 个）、事件结果（24 个）、事件变量（250 个）、事件标志（1024 个）——**控制剧情进度的核心数据**，用于跳过卡死的剧情或回退触发条件，**改前务必弄清含义**。
- **全局**：当前地图、当前角色、主角姓名、智慧/仁德/勇气/医术、战斗统计（胜/败/杀敌）、任务完成度、收纳灵魂/兽元等。

### 23.3 TKSWarpcEditor 存档模式能改的部分（角色养成数据）

进入存档模式后，界面和平时完全一样（五个标签页全部可用），但改的是**存档里那份角色快照**：

- 角色当前等级、HP/MP、八维属性、五维、剩余技能点。
- 344 个技能的学会状态——直接给主角点满技能就在这里。
- 4 个装备槽、装备技能、被动技能、使用权限。
- 状态抵抗、成长率、战后奖励、掉落物品等全部字段。

保存时只写回 `sav.N`，**不会动游戏目录里的 WarPC.dat**。

> 注意：角色数据在"进入队伍/战斗"等时机会重新计算装备加成，个别当前值可能被游戏刷新，属正常现象；改"基础值"比改"当前值"更稳。

### 23.4 TKSMatEditor 存档模式能改的部分（地图实体状态）

进入存档模式后，编辑的是**存档里那份地图实体表**（约 6000 个实体的当前状态）：

- **宝箱/机关**：把已开过的宝箱重置为未开、修改机关状态。
- **NPC**：位置、朝向、显示状态（找回"消失"的 NPC 或让挡路 NPC 让开）。
- **传送点 / 随机遇敌区**：在当前进度上修改目的地、遇敌概率。
- **剧情触发器与脚本链状态**：配合事件标志（TKSSaveEditor 的"事件"页）解救卡死的剧情——两边数据互相配合，跳剧情通常需要同时改。

保存时只写回 `sav.N`，**不会动游戏目录里的 TKMat.Dat**。

### 23.5 推荐改档流程

1. **游戏内先存一个新档**（专门用来改），然后**完全退出游戏**——游戏运行中改存档会被覆盖或导致数据错乱。
2. 复制一份 `save` 文件夹到别处做总备份（编辑器虽会自动生成 `.bak`，多一层保险）。
3. 按 23.1 的分工表，用对应编辑器打开**同一个槽位**修改并保存。
4. **一次只开一个编辑器改存档**：三个编辑器保存时都会重写整个 `sav.N` 文件，如果同时打开两个各改各的，后保存的会把先保存的修改覆盖掉。正确做法是：改完 A 保存并关闭（或重新加载），再开 B。
5. 进游戏读档验证。发现异常就用 `.bak` 或总备份回滚。

### 23.6 常见改档需求速查

| 我想…… | 工具与位置 |
|---|---|
| 改钱、加道具 | TKSSaveEditor → 总览 / 背包 |
| 换队伍成员 | TKSSaveEditor → 队伍 |
| 给角色升级 / 点满技能 / 换装备 | TKSWarpcEditor → 存档模式 |
| 提升角色属性上限 | TKSWarpcEditor → 存档模式 → 核心属性 |
| 重开已开过的宝箱 | TKSMatEditor → 存档模式 |
| 剧情卡死想跳过 | TKSSaveEditor → 事件 页 + TKSMatEditor → 存档模式（配合修改，先看编辑器内帮助） |
| 改主角名字 | TKSSaveEditor → 全局 |
| 修改读档界面显示的信息 | TKSSaveEditor（保存队伍/金钱时自动同步 `N.sav` 索引） |

### 23.7 注意事项

- 存档修改**无法导出为 MOD**——MOD 机制只针对游戏数据文件，存档是你的个人进度，只能直接改。
- 事件开关/标志/变量是剧情引擎的"神经系统"，不确定含义的项不要乱动，一次只改一处并记录改了什么。
- 如果你的存档是在**启用扩容 MOD**（新增角色）的情况下建立的，编辑器会自动识别扩容后的角色数量，属正常现象；但这类存档回到无 MOD 环境可能无法读取。
- 金钱上限原版为 30000，除非启用了启动器的"金钱上限提升"补丁，否则填再大游戏里也会被截回。

## 二十四、常见问题 FAQ

**Q1：双击 exe 没反应/闪退？**
确认 `libs/` 文件夹和 exe 在同一目录（薄版 exe 依赖它）。杀毒软件可能误报拦截，请添加信任。

**Q2：编辑器里物品/技能显示的是编号而不是名字？**
说明 `TKT.dat`（文本库）没加载成功。请用"加载 TKS 目录"选择包含 TKT.dat 的完整游戏目录。

**Q3：我改了 TKItem.dat，进游戏却没变化？**
① 确认在编辑器里点过"✅ 应用"再保存；② 确认改的目录就是你启动的那个游戏的目录；③ 如果通过启动器启动且启用了相关 MOD，MOD 数据可能覆盖了你的直接修改。

**Q4：改坏了怎么恢复？**
找到同目录下的 `.bak` 文件（如 `TKItem.dat.bak`），删掉改坏的文件，把 `.bak` 重命名回原名。存档同理（`.sav.bak`）。都没有就用你开工前的完整备份。

**Q4.1：改了存档进游戏没变化 / 数据错乱？**
① 确认改的时候游戏已完全退出；② 确认改的是你实际读取的那个槽位；③ 是否同时开了多个编辑器改同一存档（后保存的会覆盖先保存的，见第二十三章 23.5）。

**Q5：游戏启动后卡死/黑屏？**
用启动器逐个取消可选补丁排查；MOD 逐个禁用排查。Wine/安卓环境确认 `no_suspend` 为 `true`。

**Q6：MOD 提示"CRC 不匹配"或"参考目录无效"？**
MOD 是基于原版数据做的差异包。如果你的游戏文件已被修改过，可能对不上。准备一份纯净原版游戏目录作为参考目录即可。

**Q7：新建的物品/角色在游戏里不出现？**
新增数据（超出原版数量上限的部分）必须**通过 TKSLauncher 启动**游戏才能生效——启动器的扩容补丁负责解除原版上限。

**Q8：可以同时开多个编辑器吗？**
可以，但不要同时用两个编辑器保存同一个文件；也不要在游戏运行中保存游戏数据文件。
