# 更新记录

## TKS子青套件 V1.4

> 2026.09.30

### 编辑套件

1. 新增一键清除缓存脚本，可清除运行缓存与注册表设置，恢复编辑器默认配置
2. 新增 TKSWarpcEditor 的扩展技能和扩展技能效果配置
3. 新增 TKSSkillEditor 与 TKSKonEditor 的扩展功能，改善新增删除复制粘贴的操作体验
4. 优化 TKSActEditor 布局与名称显示，新增标注控制与飘字预览开关，改善图层编辑效果
5. 优化 TKSWardataEditor 支持扩展敌人和扩展物品
6. 优化 TKSItemEditor 支持扩展物品，改善布局与物品文本颜色解析，物品弹窗支持扩展物品
7. 优化全项目系统性结构，改善字段说明提示
8. 优化全部编辑器主题体系，视觉更加现代统一，支持现代主题与经典主题的深色与浅色切换

### 启动器

1. 新增生成启动器功能，可将补丁与已选MOD一键生成为独立覆盖包，现在能够脱离启动器直接运行，也就是Win7系统可以正常兼容了
2. 新增宽屏补丁，支持剧情地图与战场的16:9分辨率显示，其它界面居中显示
3. 新增技能扩展补丁，扩大技能总数与每个角色可学习的技能数量，注意：会增加存档大小，旧存档可以在新版使用，但新存档无法在旧版使用
4. 新增存档扩容补丁，用于兼容技能扩展导致的存档体积增加问题
5. 新增冰冻扣内力飘字颜色修复补丁，冰雪术的扣内力效果现在是正常的蓝色飘字了
6. 新增陷阱击杀获得经验和JP补丁，陷阱击杀和上个版本的召唤物击杀现在都能够获得经验了
7. 修复武器导致状态无法触发的异常，装备衣服和饰品不会再影响武器攻击时的效果触发了
8. 优化战场血条补丁样式，增加血条格子，颜色根据百分比由绿橙红动态变化
9. 升级物品补丁为物品扩展补丁，支持扩展物品与新图标
10. 升级商店补丁为商店扩容补丁，支持扩展物品买卖

### 子青版

1. 剑庐地图新增 青木弓 拾取点
2. 揽仙镇地图新增 金乌剑 拾取点

重要提醒：本次更新增加了技能扩容补丁，存档体积会增加，老版本不兼容新存档

## TKS子青套件 V1.3

> 2026.08.30

### 编辑套件

1. 重构了主题样式，视觉上更加现代化一些
2. 新增 TKSWarpcEditor 物理抵抗字段
3. 优化 TKSWarpcEditor 人物技能效果选择器范围，支持选到新增的TKKon数据

### 启动器

1. 新增标准模式和兼容模式切换，标准模式下启用所有的.tkspatch补丁，兼容模式下只启用.tksmod，支持在其它作者的MOD版本中使用子青版美化MOD
2. 新增战场血条补丁，在每一个角色头顶显示生命条和内力条
3. 新增战场状态显示补丁，在每一个角色头顶显示当前已经中了的状态
4. 新增召唤物击杀敌人结算经验和JP补丁
5. 新增扩展角色允许加入战场作为敌人的补丁，扩展原版对此的限制

重要提醒：本次更新由于增加了兼容模式，所以移除了对其它MOD的兼容性补丁！启动其它作者MOD时请务必使用兼容模式！兼容模式下将不对其它作者的版本进行补丁修正。

## TKS子青套件 V1.1

> 2026.08.05

### 编辑套件

1. 新增复刻游戏菜单的图鉴，动态显示角色入队条件、物品获得地点或方式、异常状态解释等，所有MOD都可用
2. 新增 TKSWarpcEditor 编辑器表格编辑模式
3. 新增跨编辑器目录记忆：任一编辑器导出 MOD 时选择的参考目录会自动保存，其它编辑器再导出时默认加载该目录
4. 新增跨编辑器目录记忆：任一编辑器「加载TKS目录」选择的游戏目录会自动保存，其它编辑器再加载时默认定位到该目录
5. 新增编辑器单实例保护：同一编辑器重复启动时弹窗提示并退出新实例，避免多窗口同时编辑导致数据错乱（不同编辑器之间互不影响）
6. 修复精灵表编辑器批量导入图片时，如果满足行列数量，行列却被重新计算的问题
7. 修复 TKSWarpcEditor 存档模式编辑技能进度值的方式
8. 优化 TKSJvgEditor 导入图片逻辑，增加BBOX裁剪和自动重算色板复选框
9. 优化 TKSWarpcEditor 和 TKSSkillEditor 的技能编辑提示，角色如果可学的同一技能组下技能超过12个显示提醒

### 启动器

新增BUG修复补丁：

1. 新增战斗技能菜单数量溢出保护，如果同一个技能组的技能超出了12个，则战斗中最多显示12个，超出的不显示
2. 新增剧情地图加速配置
3. 修复剧情出现需要主角单挑时异常
4. 修复金钱超过30000时坐船判定异常
5. 修复在桃源乡或者旅馆休息时无法恢复的问题

### 额外补丁

由于很多玩家要用启动器把奉孝版和子青版一起勾选着玩，就会出现一些未知问题，因为奉孝版的启动器是魔改过的。
建议同时只运行同一个作者的MOD。

做了以下优化：

1. AI增强了对奉孝版的兼容性，有冲突的补丁不会生效
2. 新增赌场限制移除补丁，使用启动器运行奉孝版时生效

### 子青版MOD

1. 修复剑庐对话错别字
2. 新增决战时英雄亭内酒剑仙，可传送回剑庐
3. 调整了扩展人物的武术技能不超过12个，防止数据溢出导致战斗异常
4. 调整了扩展人物的部分参数

  零引用对话框类、孤儿导入等
- **热点单点化**: item/skill/kon/shop 四家逐字重复的 .tksmod 导出/导入编排
  (每家约 150 行) 收敛为 mod_exporter 模板函数 + 声明式 spec; .bak 备份块、
  PNG 编码器(×4)、游戏调色板(×2)、缩放画布类(×2) 各归一处
- **巨型文件拆分**: act_editor 4522→3107 行(+4 模块)、spritesheet_editor 3873→1084
  行(+3 模块)、mat_editor 5557→3930 行(+2 模块)
- **构建单源化**: 编辑器清单单一注册表 build/editors_registry.py;
  Nuitka 命令构造抽公共基座(39 条命令与重构前逐字节一致)
- **顺带修复**: kon 导入 MOD 后漏清撤销栈; cli_launcher 缺仓库根 sys.path;
  skill 编辑器 `_apply_edit` 存在一处疑似未写回字段的问题, 待人工确认(见 docs)
