## 0. 数据加载机制

所有调用者通过同一模式将 TKKon 记录载入全局变量：

```c
qmemcpy(&byte_9D6C28, (const void *)(40 * kon_id + 10290840), 0x28u);
// 10290840 = 0x9D0698 → TKKon.dat 解压后数据起始地址
// 40 字节/条, 0x28 = 40
```

拷贝后的全局变量与 TKKon 字段偏移的对应关系：

| 全局变量 | 记录内偏移 | 对应字段 |
|----------|-----------|---------|
| `byte_9D6C28` | offset 0 (低字节) | **exec_mode** |
| `byte_9D6C29` | offset 1 (高字节) | **exec_mode** |
| `byte_9D6C2A` | offset 2 (低字节) | **target_param** |
| `byte_9D6C2B` | offset 3 (高字节) | **target_param** |
| `byte_9D6C2C` | offset 4 (低字节) | **target_filter** |
| `byte_9D6C2D` | offset 5 (高字节) | **target_filter** |
| `byte_9D6C2E`+ | offset 6+ | damage_base 等后续字段 |

| 值 | 语义 | 证据来源 |

### 低字节 (byte_9D6C28, offset 0) — 范围形状

**仅在 sub_43D53C 中被读取一次**（line 33: `v14 = byte_9D6C28`），其他所有函数均不读取此字节。

```c

| 值 | 语义 | 证据 |
|----|------|------|
| **= 0** | **菱形扩散** — 以高字节值为半径，向 4 个方向扩展菱形区域 | sub_43D53C:47-113, 4 臂扩展循环 |

**注意**: 低字节只有在高字节 > 0 时才有意义。高字节 ≤ 0 时，函数走其他分支，低字节不被检查。

### 低字节 (byte_9D6C2C, offset 4) — 阵营匹配

**两个函数均读取此字节**，且语义一致。

#### sub_43D53C:134-158

## 4. 战斗引擎完整流水线

```
1. qmemcpy(&byte_9D6C28, 40*kon_id + 0x9D0698, 0x28)
   将 TKKon 记录载入全局变量区

2. sub_43D53C(caster, x, y)           ← 攻击区域标记
   ├── byte_9D6C29 (exec_mode 高):  攻击距离, <0 返回 0, >0 菱形层数
   ├── byte_9D6C28 (exec_mode 低):  范围形状, 0=菱形 !=0=单体
   ├── byte_9D6C2D (target_filter 高): 格子类型, 0=全部 1=仅角色 2=仅空地
   └── byte_9D6C2C (target_filter 低): 阵营匹配, 0=对立 1=同 2=任意
       → 输出: byte_952D54[32×32] 网格 (1=可攻击格)

3. sub_43D8B0(caster, tx, ty, a4)    ← 效果区域验证
   ├── 校验 (tx,ty) 在 byte_952D54 攻击区内
   ├── byte_9D6C2B (target_param 高): 效果半径, <0=全场 -2=排除中心
   ├── byte_9D6C2A (target_param 低): 扩散开关, 0=启用 !=0=单体
   └── byte_9D6C2C (target_filter 低): 阵营匹配 (复用)
       → 输出: byte_953154[32×32] 网格 (1=有效目标格)

4. sub_442AB0()                       ← 收集目标列表
   扫描 byte_953154 中所有值为 1 的格子
   → 输出: byte_9D6FA4[] 目标角色 ID 数组, byte_9D6FC4 目标数量
```

### 两级过滤对比

| | sub_43D53C (攻击区) | sub_43D8B0 (效果区) |
|---|---|---|
| **作用** | 决定"从哪里能打到" | 决定"打到后波及多大范围" |
| **中心点** | 施法者位置 | 目标位置 |
| **距离控制** | exec_mode 高字节 | target_param 高字节 |
| **形状控制** | exec_mode 低字节 | target_param 低字节 |
| **格子类型** | target_filter 高字节 ✓ | 不检查（仅处理有角色格） |
| **阵营匹配** | target_filter 低字节 ✓ | target_filter 低字节 ✓ |

### 自身技能判定

```
