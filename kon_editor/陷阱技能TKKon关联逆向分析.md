## 核心发现：两层 TKKon 体系

**WarPC 层** (`WarPC[273+skill_slot]`): 所有 5 个陷阱全部指向 **TKKon[639]**
- 吕蒙 (Char#20)、曹操 (Char#2) 等拥有陷阱的角色，山崩/泥沼/漩渦/火焰/滾木 → TKKon[639]
- TKKon[639] = `[4]=1025("不明前因、難知後果，現在凡世之")` — 通用对话文本，非效果数据
- 瘴氣陷阱 (slot 10): 所有角色均未映射 (值=65535)

**运行时层**: 陷阱触发后通过 `陷阱类型 + 551` 映射到 TKKon[552-557]

## 结论

1. **WarPC→TKKon[639]** 是「陷阱类别标记」— 仅用于UI显示，所有5个陷阱共用
2. **陷阱类型 + 551 → TKKon[552-557]** 才是实际效果数据入口
3. 三个陷阱有**硬编码的元素增益**: 火焰(火×2)、漩渦(水×2)、瘴氣(毒×2)
4. 山崩、泥沼、滾木无硬编码增益，效果完全由 TKKon 条目定义
