# WarPC / TKItem / TKSkill / TKKon / TKAct 五文件完整关联分析报告

## 概述

本文档分析《三国群侠传》(TKS) 中五个核心游戏数据文件的完整关联关系，基于 TKS.exe 反编译 (PE dump) 和实际数据验证。

## 三、逐条关联分析

### 3.1 WarPC → TKItem (装备系统)

**关联方式**: WarPC 的 `equip_id` / `equip_idx` / `drop_item` 字段 → TKItem 索引

| WarPC 字段 | 偏移 | 数量 | 说明 |
|-----------|------|------|------|
| equip_idx[0-3] | [69]-[72] (138-144字节) | 4 | 装备物品的 **索引** (运行时计算) |
| equip_id[0-3] | [73]-[76] (146-152字节) | 4 | 装备物品的 **item_id** (存档原始值) |
| drop_item[0-2] | [270]-[272] (540-544字节) | 3 | 战后可能掉落的物品 ID |

**反编译证据**: `sub_4173F8` 在初始化时将 `equip_id` 匹配到 `equip_idx`:
```c
for each character:
    for equip_slot in [0..3]:
        search all TKItem records for matching item_id
        set equip_idx = found index (or -1 if not found)
```

**权限校验** (`sub_41928C`): WarPC.use_right 字段与 TKItem.equip_type 做位与校验，控制角色能否装备/使用该物品。

**数据验证**: 主角 #0 通过 `equip_id` 字段引用装备物品；37 种不同物品 ID 出现在角色装备中。

---

### 3.2 WarPC → TKSkill (技能装备/学习系统)

**关联方式**: WarPC 的 `equip_skill` / `passive` / `skill_learn` 字段 → TKSkill 索引

| WarPC 字段 | 偏移 | 数量 | 说明 |
|-----------|------|------|------|
| equip_skill[0-3] | [82]-[85] (164-170字节) | 4 | 当前装备的**主动/指令技能** |
| passive[0-1] | [86]-[87] (172-174字节) | 2 | 当前装备的**被动技能** |
| skill_learn[0-343] | [88]-[259] (176-518字节) | 344 | 每个技能的**学习状态** (1 byte each) |

**skill_learn 状态机** (反编译 sub_41E248/sub_42234C/sub_4189BC 交叉验证):
```
0  → 不会
1-9 → 等待学 (进展累积, 来自 ref_type 累加)
10  → 可以学 (出现在待学习技能列表中)
20  → 组技能学会 (父技能, 起分组作用)
30  → 子技能学会 (独立技能, 可装备使用)
40  → 临时态 (不出现在存档)
```

**反编译证据**: `sub_42234C` 在装备应用时遍历 `equip_skill[0-3]`：
```c
for (v10 = 0; v10 <= 3; ++v10) {
    if (a2[84 + v10] != -1)           // equip_skill slot
        sub_422BBC(a1, a2, a2[84 + v10]);  // apply skill effects
}
```

`sub_422BBC` 根据 TKSkill.type 分支执行不同的属性加成效果。

### 3.3 WarPC → TKKon (技能→战场动作映射)

**关联方式**: WarPC 的 `skill_effect` 字段 → TKKon 记录索引

| WarPC 字段 | 偏移 | 数量 | 说明 |
|-----------|------|------|------|
| skill_effect[0-253] | [273]-[526] (546字节起) | ~254 | 每个 type=0 指令技能 → TKKon ID |

**这是最关键的映射层**：WarPC 的 `skill_effect` 表将每个 type=0（指令型）技能映射到一个具体的 TKKon 战场动作记录。

**数据验证** (主角 #0):
```
TKSkill#0  [移動]       → TKKon#0  (普攻)
TKSkill#11 [回 復 術]    → TKKon#7  (治疗术)
TKSkill#12 [回 復 術]    → TKKon#8  (治疗术·大)
TKSkill#14 [靈 息 術]    → TKKon#9  (回魔术)
TKSkill#107[天 雷 術]    → TKKon#61 (雷系法术)
...
```

**不同角色可以有不同的 TKKon 映射**，这解释了为何同一技能在不同角色身上表现不同（如 BOSS 版本的技能动作可能不同）。

**反编译证据** (`sub_4458B0` 战斗执行):
```c
// 获取当前角色的 TKKon 索引
word_9D6C7A = word_9D7494[527 * character_id];
// ↓ word_9D7494 即 WarPC 的 skill_effect 区域加载后的地址
if (!word_9D6C7A)
    word_9D6C7A = word_9D6C84;       // 默认后备值

// 加载 TKKon 记录 (40 字节) 到战斗工作区
qmemcpy(&byte_9D6C28,
    (const void *)(40 * word_9D6C7A + 0x9D0698), 0x28u);
```

### 3.4 TKItem → TKSkill (物品学习技能)

**关联方式**: TKItem 的 `equip_learn` / `use_learn` / `attach_skill` 字段 → TKSkill 索引

| TKItem 字段 | 偏移 | 说明 |
|------------|------|------|
| attach_skill | [21] (42字节) | 装备后施加的技能被动效果 (不写入技能栏) |
| equip_learn | [22] (44字节) | 装备后升级已有技能到 10 级 |
| use_learn1 | [23] (46字节) | 使用时学会技能 (10级) |
| use_learn2 | [24] (48字节) | 使用时学会技能2 (10级) |

**数据统计**:
- `attach_skill`: 76 条物品引用
- `equip_learn`: 12 条物品引用
- `use_learn1`: 27 条物品引用
- `use_learn2`: 4 条物品引用

**反编译证据** (`sub_41E40C` 物品使用):
```c
if (v15[23]) {  // use_learn1
    if (v15[23] > 0 && byte_757FB8[1054 * a2 + v15[23]] >= 1
        && byte_757FB8[1054 * a2 + v15[23]] < 20)
        byte_757FB8[1054 * a2 + v15[23]] = 10;  // set to "can learn"
}
```

### 3.6 TKSkill → TKSkill (技能树自身引用)

**关联方式**: TKSkill 的 `ref_skill[0-7]` / `ref_type[0-7]` 字段 → TKSkill 自身

| TKSkill 字段 | 偏移 | 数量 | 说明 |
|-------------|------|------|------|
| ref_skill[i] | 8+i×4 | 8 组 | 目标技能索引 |
| ref_type[i] | 10+i×4 | 8 组 | 技能学习进度权重 |

**进度累加机制**: 当源技能被学会后，`ref_type` 值累加到目标技能的 `byte_757FB8` (skill_learn)，达到 ≥10 时目标技能变为"可以学"状态。

## 四、两条主要战斗路径

### 路径 A: 角色使用技能

```
玩家选择技能
    ↓
装备系统确定技能索引 (WarPC.equip_skill[0-3])
    ↓
查 WarPC.skill_effect 表 → 获取 TKKon ID
    ↓
TKKon.cond_id → 加载 TKAct 动画
    ↓
TKKon 战斗参数 (damage_base, accuracy, 状态等) → 执行战斗效果
    ↓
TKSkill 效果加成 (sub_422BBC: atk_pct, def_pct 等) → 应用到角色属性
```

### 路径 B: 角色使用物品

```
玩家选择物品
    ↓
TKItem.battle_anim → 直接获取 TKKon ID
    ↓
TKKon.cond_id → 加载 TKAct 动画
    ↓
TKKon 战斗参数 (hp_restore, mp_restore, damage_base) → 执行效果
    ↓
sub_41E40C: TKItem 属性加成 (hp_heal, atk, def 等) → 应用到角色
    ↓
sub_41E40C: TKItem.use_learn → 学会技能 (写入 WarPC.skill_learn)
```

## 五、关联矩阵总结

| 源文件 → 目标 | 关联方式 | 字段 | 反编译函数 |
|-------------|---------|------|-----------|
| **WarPC → TKItem** | 装备物品 | equip_id[0-3] → item_id | sub_4173F8, sub_41928C |
| **WarPC → TKItem** | 战后掉落 | drop_item[0-2] → item_id | (战斗结算) |
| **WarPC → TKSkill** | 装备技能 | equip_skill[0-3] → TKSkill index | sub_42234C |
| **WarPC → TKSkill** | 被动技能 | passive[0-1] → TKSkill index | sub_422BBC |
| **WarPC → TKSkill** | 技能学习 | skill_learn[344] → TKSkill 状态 | sub_41E248 |
| **WarPC → TKKon** | 技能战场动作 | skill_effect[254] → TKKon index | sub_4458B0, sub_4434BC |
| **TKItem → TKSkill** | 学习/附加技能 | equip_learn/use_learn/attach_skill | sub_41E40C, sub_42234C |
| **TKItem → TKKon** | 物品战场动作 | battle_anim → TKKon index | sub_4434BC |
| **TKSkill → TKSkill** | 技能树 | ref_skill[0-7] → TKSkill index | sub_41E248 |
| **TKKon → TKAct** | 动画资源 | cond_id → TKAct index | sub_4434BC (qmemcpy) |

### 无直接关联的组合

| 组合 | 原因 |
|------|------|
| TKSkill → TKKon | 通过 WarPC.skill_effect 间接连接 |
| TKSkill → TKAct | 通过 TKKon.cond_id 间接连接 |
| TKSkill → TKItem | 通过 WarPC 装备系统间接连接 |
| TKItem → TKAct | 通过 TKKon.cond_id 间接连接 |
| TKAct → 任何文件 | 纯资源文件, 不引用其他文件 |
