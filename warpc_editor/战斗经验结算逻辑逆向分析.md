## 一、核心数据结构

### 战斗运行时变量

| 变量 | 类型 | 含义 |
|------|------|------|
| `dword_9D6F14` | int32 | 经验总池（共享经验，战斗结束后平分给全队） |
| `dword_9D6F18` | int32 | JP（技能点）总池 |
| `dword_9D6F20[i]` | int32×6 | 第 i 名队员的个人经验（击杀奖励 + 环境探索加成） |
| `dword_9D6F38[i]` | int32×6 | 第 i 名队员的个人 JP |
| `byte_9DF781[i]` | byte | 战场单位 i 的**战斗等级**（来自战场配置 `byte_953830`） |
| `byte_9DF761[i]` | byte | 单位阵营标识（100=玩家方, <10=敌方） |
| `word_9D7084[527*i]` | int16 | 战斗单位 i 的当前 HP (battle_unit[i].field[5]) |
| `arglist` | int32 | 战斗金钱累积池 |

### WarPC 经验相关字段

| 字段偏移 | Word索引 | 名称 | 说明 |
|----------|----------|------|------|
| byte 4 | [2] | level | 角色等级 |
| byte 6 | [3] | current_exp | 当前已积累经验（距离下次升级的进度） |
| byte 8 | [4] | exp_to_next | 升至下一级所需经验 |
| byte 72 | [36] | exp_bonus | 战斗经验增加%（来自"鬼才"系列主动技能） |
| byte 74 | [37] | jp_bonus | 战斗JP增加%（来自"天才"系列主动技能） |
| byte 66 | [33] | special_flag | 特殊能力标志位（装备 TKItem[20]） |
| byte 536 | [268] | jp_reward | 击败后获得技能点数（直接值） |
| byte 538 | [269] | gold_reward | 击败后获得金钱基数 |
| byte 528 | [264] | growth_early | 成长率初期 (Lv1-20) |
| byte 530 | [265] | growth_mid | 成长率中期 (Lv21-40) |
| byte 532 | [266] | growth_late | 成长率后期 (Lv41-60) |

### special_flag 位定义 (field[33])

| bit | 标志 | 效果 | 来源装备 |
|-----|------|------|---------|
| 0 | JP×2~3 | 战后JP随机乘以2或3 | 無方戒 |
| 1 | 战后全恢复 | HP/MP全恢复+清除异常状态 | 無雙戒 |
| 2 | 经验×2平分 | 经验加倍后平分给队友 | 無嗔戒 |
| 3 | 经验独得 | 全部经验归一人独享 | 無道戒 |

## 二、经验获取公式（战斗中实时累积）

### 来源函数: sub_4400DC（攻击结算，位于 0x4400DC，3000+ 汇编指令）

该函数在每次攻击命中后执行，根据攻击结果（敌人存活/死亡）分别计算经验。

### A. 造成伤害但未击杀（敌人存活）

**触发条件**: 攻击者为玩家方 (`byte_9DF761[attacker] == 100`) 且目标为敌方 (`byte_9DF761[target] < 10`)

**公式**:
```
经验池(dword_9D6F14) += 2 × 伤害值 × (敌人等级 + 3) / 3
```

**反汇编位置**: 0x441B1B ~ 0x441B71
```asm
; 先减少敌人HP
sub  word_9D7084[enemy*2], damage

; 计算经验 (仅当攻击者是玩家方、目标是敌方时)
movsx eax, byte_9DF781[target]   ; eax = 敌人战斗等级
imul  [damage]                    ; eax = 等级 × 伤害
cdq
idiv  3                           ; eax = 等级 × 伤害 / 3
add   eax, [damage]              ; eax = 伤害 × (等级 + 3) / 3
add   eax, eax                   ; eax = 2 × 伤害 × (等级 + 3) / 3
add   dword_9D6F14, eax          ; 加入经验总池
```

### B. 击杀敌人（敌人HP ≤ 伤害）

**触发条件**: 同上，且本次伤害 ≥ 敌人当前HP

**公式**:
```
击杀者个人经验(dword_9D6F20[killer]) += 敌人剩余HP × (敌人等级 + 3) / 2
经验总池(dword_9D6F14)              += 敌人剩余HP × (敌人等级 + 3)
```

> **重要**: 这里的「敌人剩余HP」是致命一击 **之前** 敌方的当前HP值，即敌人最后的生命值。

> **注意**: A 和 B 互斥 — 同一次攻击只会触发其中之一。击杀时不再额外获得伤害经验。

**反汇编位置**: 0x441827 ~ 0x441919
```asm
; 条件判断: enemy_HP <= damage → 触发击杀
cmp   eax, edx                   ; HP vs damage
jg    survive_branch             ; HP > damage → 存活分支

; 击杀分支
movsx eax, word_9D7084[enemy*527] ; eax = 敌人当前HP (致命一击前)
movsx ecx, byte_9DF781[enemy]     ; ecx = 敌人等级
imul  ecx                         ; eax = HP × 等级
cdq / idiv 3                      ; eax = HP × 等级 / 3
add   eax, enemy_HP               ; eax = HP × (等级 + 3) / 3
; 计算 3/2 倍
mov   [var_48], eax               ; var_48 = HP × (等级+3) / 3
sar   eax, 1                      ; eax = var_48 / 2
add   [var_48], eax               ; var_48 = HP × (等级+3) / 2

; 击杀者个人奖励
add   dword_9D6F20[killer*4], var_48  ; 个人经验 += HP×(等级+3)/2

; 经验池奖励 (个人的2倍)
shl   [var_48], 1                     ; var_48 × 2
add   dword_9D6F14, var_48           ; 经验池 += HP×(等级+3)
```

### C. 击杀时 JP 获取

**公式**:
```
JP总池(dword_9D6F18) += jp_reward × (敌人等级 + 3) / 3
```

**反汇编位置**: 0x441921 ~ 0x441959
```asm
movsx eax, word_9D7292[enemy*527*2]  ; eax = jp_reward (WarPC field[268])
movsx ecx, byte_9DF781[enemy]         ; ecx = 敌人等级
imul  ecx                             ; × 等级
cdq / idiv 3                          ; / 3
add   eax, jp_reward                  ; + jp_reward = jp_reward × (等级+3) / 3
add   dword_9D6F18, eax              ; 加入JP总池
```

### D. 击杀时金钱获取

**公式**:
```
金钱池(arglist) += 2 × gold_reward × (敌人等级 + 3) / 3
```

**反汇编位置**: 0x44195F ~ 0x4419A2
```asm
movsx eax, word_9D7294[enemy*527*2]  ; eax = gold_reward (WarPC field[269])
movsx ecx, byte_9DF781[enemy]         ; ecx = 敌人等级
imul  ecx / idiv 3                    ; × 等级 / 3
add   eax, gold_reward                ; = gold_reward × (等级+3) / 3
add   eax, eax                        ; × 2
add   arglist, eax                    ; 加入金钱池
```

### E. 击杀时掉落物品

**反汇编位置**: 0x4419B7 ~ 0x441AE9

| WarPC字段 | Word索引 | 掉落概率 | 说明 |
|-----------|----------|---------|------|
| field[270] | drop_item0 | 100% | 必掉落 |
| field[271] | drop_item1 | 20% (random(1000) < 200) | 高概率掉落 |
| field[272] | drop_item2 | 5% (random(1000) < 50) | 低概率掉落 |

### F. 环境探索被动技能（拾取地块时）

**来源函数**: sub_434510 (0x434510)

当角色拥有「环境探索」被动技能（reaction_group == 7）并拾取战场地块时：

```c
// sub_434510 line 48-51
if ( word_9D70CC[527 * active_unit] == 7 )  // 反应组 = 环境探索
{
    dword_9D6F20[active_unit] += 50 * passive_skill_id - 16000;
    dword_9D6F38[active_unit] += 5 * passive_skill_id - 1605;
}
```

| 被动技能 | 技能ID | 额外经验/地块 | 额外JP/地块 | 公式验证 |
|---------|--------|------------|-----------|---------|
| 环境探索1 | 321 | +50 | +0 | 50×321-16000=50, 5×321-1605=0 |
| 环境探索2 | 322 | +100 | +5 | 50×322-16000=100, 5×322-1605=5 |
| 环境探索3 | 323 | +150 | +10 | 50×323-16000=150, 5×323-1605=10 |

## 三、战后经验分配逻辑

### 来源函数: sub_43B7FC (0x43B7FC)

战斗胜利后，由 `sub_43BFE8(1)` → `sub_43B7FC()` 执行经验分配。

### 第一阶段：特殊装备效果处理

遍历所有存活的队伍成员，检查 `special_flag` (field[33] = v18[28]):

```c
// 统计存活人数
v9 = 0;  // 存活计数
v13 = -1; // "经验×2平分"持有者
v12 = -1; // "经验独得"持有者

for each party_member:
    if (HP > 0):
        v9++
        if (special_flag & 0x02):  // bit1: 战后全恢复
            HP = HP_max; MP = MP_max; 清除异常状态
        if (special_flag & 0x04):  // bit2: 经验×2平分
            v13 = this_member
        if (special_flag & 0x08):  // bit3: 经验独得
            v12 = this_member
```

### 第二阶段：经验池重分配

```c
if (存活人数 == 0):
    经验池 = 0  // 全灭则无经验

else if (v13 >= 0 && 存活人数 > 1):
    // "经验×2平分"效果 (無嗔戒)
    per_share = ceil(经验池 / 存活人数)
    经验池 -= per_share                    // 取出该人的份额
    boosted = 个人经验[v13] + per_share
    if (boosted <= 15000):
        boosted *= 2                       // 加倍
    else:
        boosted = 30000                    // 上限
    经验池 += boosted                      // 加倍后的经验归入总池
    个人经验[v13] = 0                      // 该人不再参与后续分配
    remaining = 存活人数 - 1
    if (v12 == -1):                        // 无"经验独得"
        经验池 = ceil(经验池 / remaining)  // 在剩余人之间平分

else:
    // 正常平分
    if (v12 == -1):  // 无"经验独得"
        经验池 = ceil(经验池 / 存活人数)
```

### 第三阶段：分配到个人并应用加成

```c
for each party_member (i = 0 to byte_9DF886):
    if (HP <= 0): continue  // 死亡角色不获得经验

    // 基础分配
    个人经验[i] += 经验池        // 每人获得等分后的池
    个人JP[i] += JP池

    // 技能加成 (鬼才/天才)
    if (exp_bonus > 0):  // field[36], 来自主动技能
        个人经验[i] += ceil(个人经验[i] × exp_bonus / 100)
    if (jp_bonus > 0):   // field[37]
        个人JP[i] += ceil(个人JP[i] × jp_bonus / 100)

    // 全局加倍标志
    if (dword_755C80 & 0x20):
        个人经验[i] *= 2

    // "经验×2平分"持有者已经获得了加倍经验，此处清零
    if (v13 == i):
        个人经验[i] = 0

    // "经验独得"效果：其他人清零
    if (v12 >= 0 && v12 != i):
        个人经验[i] = 0

    // 经验上限
    if (个人经验[i] > 30000):
        个人经验[i] = 30000
```

### 第四阶段：升级处理

```c
    // 升级循环
    remaining_exp = 个人经验[i]
    while (exp_to_next <= remaining_exp):
        remaining_exp -= exp_to_next
        sub_43066C(battle_unit[i])  // 升级!
        HP = HP_max                 // 升级后满血

    // 将剩余经验存入角色
    current_exp += remaining_exp     // field[3] += 剩余
    exp_to_next -= remaining_exp     // field[4] -= 剩余 (距下次升级的差值)
```

### 第五阶段：JP 结算

```c
    // JP 特效
    if (special_flag & 0x01):        // JP×2~3 (無方戒)
        个人JP[i] *= random(2, 3)    // 随机乘以2或3
    elif (dword_755C80 & 0x20):      // 全局标志
        个人JP[i] *= 2

    // 累加到角色总JP
    jp_total += 个人JP[i]            // field[31] (byte offset 62)
    if (jp_total > 30000):
        jp_total = 30000
```

## 四、升级公式

### 来源函数: sub_43066C (0x43066C)

### 升级所需经验公式

```
exp_to_next = 8 × level² + 92
```

| 等级 | 升级所需 | 等级 | 升级所需 | 等级 | 升级所需 |
|------|---------|------|---------|------|---------|
| 1 | 100 | 10 | 892 | 30 | 7,292 |
| 2 | 124 | 15 | 1,892 | 40 | 12,892 |
| 3 | 164 | 20 | 3,292 | 50 | 20,092 |
| 5 | 292 | 25 | 5,092 | 59 | 27,940 |

> 验证: 呂布初始exp_to_next=5092 → Lv25: 8×625+92=5092 ✓  
> 验证: 張角初始exp_to_next=7292 → Lv30: 8×900+92=7292 ✓

### 属性成长公式

```python
# 成长率除数选择 (基于当前等级)
if level < 21:
    divisor = growth_early   # WarPC[264], 例: 五爪金龍=27, 呂布=20
elif level < 41:
    divisor = growth_mid     # WarPC[265], 例: 五爪金龍=24, 呂布=25
else:  # level >= 41
    divisor = growth_late    # WarPC[266], 例: 五爪金龍=21, 呂布=25

# 六维属性成长 (HP/MP/攻击/防御/命中/闪避)
for stat in [HP基础, MP基础, 攻击, 防御, 命中, 闪避]:
    stat += stat / divisor + 1

# 速度成长 (固定+1)
speed += 1

# 升级后重置
level += 1
current_exp = 0                    # field[3] = 0
exp_to_next = 8 × level² + 92     # field[4] 重算

# 上限检查
if HP基础 > 9999: HP基础 = 9999
if MP基础 > 9999: MP基础 = 9999
```

**成长率含义**:
- divisor 越小 → 成长越快 (例: 呂布早期 divisor=20, 每级成长 = stat/20+1 ≈ 6%)
- divisor 越大 → 成长越慢 (例: 普通角色 divisor=27, 每级成长 = stat/27+1 ≈ 4.7%)

### 最高等级: 60

```c
if ( level < 60 )  // sub_43066C 入口检查
{
    // ... 执行升级
}
```

## 五、敌方等级系统

### 来源函数: sub_4307CC (0x4307CC, 战斗初始化) + sub_4302D8 (0x4302D8, 按等级成长)

### 等级加载

敌方单位的战斗等级来自战场配置数据 `byte_953830`，在战斗初始化时加载：

```c
// sub_4307CC line 216-227
byte_9DF781[unit_index] = byte_953830[scenario_index];  // 战斗等级
sub_430578(battle_unit, level, min_level, max_level, dynamic_flag);
```

### 敌方属性计算 (sub_4302D8)

敌方单位从 WarPC 基础数据（Lv1属性）开始，按成长率公式自动升级到目标等级：

```c
// sub_4302D8: 将单位从 Lv1 成长到目标等级
for (i = 1; i < target_level; i++):
    // 选择成长率除数 (同升级公式)
    if i < 21: divisor = growth_early
    elif i < 41: divisor = growth_mid
    else: divisor = growth_late

    // 六维成长
    HP += HP / divisor + 1
    MP += MP / divisor + 1
    ATK += ATK / divisor + 1
    DEF += DEF / divisor + 1
    HIT += HIT / divisor + 1
    EVA += EVA / divisor + 1
    SPD += 1

// BOSS强化乘数 (a3 = boss_multiplier, 来自 byte_953842)
if (boss_multiplier > 0):
    HP  += boss_multiplier × HP         // HP大幅增加
    MP  += boss_multiplier × MP / 4
    ATK += boss_multiplier × ATK / 8
    DEF += boss_multiplier × DEF / 8
    HIT += boss_multiplier × HIT / 12
    EVA += boss_multiplier × EVA / 12
    SPD += boss_multiplier × level / 10

// HP/MP 上限 20000
level = target_level
current_exp = 0
exp_to_next = 8 × level² + 92
```

## 八、实例计算

### 示例：Lv10 角色攻击 Lv15 敌人

**情况A - 造成200点伤害，未击杀:**
```
经验池 += 2 × 200 × (15+3) / 3 = 2 × 200 × 6 = 2400
```

**情况B - 击杀，敌人剩余100HP:**
```
击杀者个人 += 100 × (15+3) / 2 = 100 × 9 = 900
经验池     += 100 × (15+3) = 100 × 18 = 1800
```

### 示例：战后分配（3人存活，经验池=6000，击杀者个人=900）

```
1. 经验池平分: ceil(6000 / 3) = 2000 每人
2. 击杀者总经验: 2000 + 900 = 2900
   其他人总经验: 2000 + 0 = 2000
3. 假设击杀者有 exp_bonus = 30 (鬼才30%):
   击杀者: 2900 + ceil(2900 × 30 / 100) = 2900 + 870 = 3770
4. Lv10 升级需: 8×100+92 = 892
   3770 / 892 ≈ 可升4级 (892+1092+1324+1588 = 4896 > 3770, 实际升3级)
```

### 示例：盜賊嘍嘍 (jp_reward=2, gold_reward=20, Lv5)

```
JP:  2 × (5+3) / 3 = 2 × 8 / 3 = 5
金钱: 2 × 20 × (5+3) / 3 = 2 × 20 × 8 / 3 = 106
```

> 注: warpc_editor 文档记录 "盜賊嘍嘍=20→40" 是基于 Lv3 的数据:  
> 2 × 20 × (3+3) / 3 = 2 × 20 × 2 = 80... 不完全匹配。  
> 可能实际游戏中该敌人等级为 0: 2 × 20 × (0+3) / 3 = 2 × 20 × 1 = 40 ✓

## 九、关键设计特点总结

1. **经验与伤害直接挂钩** — 不是击杀固定经验值，而是每次攻击实时按伤害累积。高伤害角色自然获得更多经验。

2. **击杀奖励双重收益** — 击杀者同时获得个人奖励（HP×(Lv+3)/2）和共享池奖励（HP×(Lv+3)的1/N），实质获得约1.5~2倍于普通队员的经验。

3. **等级缩放因子 (level+3)/3** — 高等级敌人指数级提供更多经验。打低级怪获益极低，打高级怪收益巨大。

4. **升级曲线为二次方 (8×Lv²+92)** — 等级越高升级越困难，后期需要巨量经验。

5. **存活才分经验** — 死亡角色不参与经验分配（HP≤0时跳过）。

6. **经验独占/加倍机制** — 通过特殊装备（無道戒/無嗔戒）可以集中培养单一角色。

7. **30000经验上限** — 单次战斗单人最多获得30000经验，防止溢出。

8. **BOSS强化不影响经验等级** — BOSS乘数只增强属性，不改变 `byte_9DF781` 的等级值，因此BOSS的经验倍率与同等级小兵相同，但因HP极高，击杀奖励远超普通敌人。
