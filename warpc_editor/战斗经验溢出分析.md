## 分析结论：战斗经验溢出变为负数的根因

### 根本原因：`movsx` 指令对敌人等级字节的符号扩展

**这是最直接、最容易触发的根因。**

在攻击结算函数 `sub_4400DC` 中，敌人战斗等级 `byte_9DF781[target]` 被读取时使用了 **`movsx`（带符号扩展）** 指令：

**非击杀时 (0x441B58)**:
```asm
movsx   eax, byte_9DF781[ecx]   ; 将 byte 带符号扩展为 int32
imul    [ebp+var_24]            ; × 伤害值
cdq
idiv    3                        ; / 3
add     eax, [var_24]           ; + damage
add     eax, eax                ; × 2
add     dword_9D6F14, eax       ; 加入经验池
```

**击杀时 (0x4418C3)**:
```asm
movsx   ecx, byte_9DF781[edx]   ; 将 byte 带符号扩展为 int32
```

`movsx` 将字节作为**有符号数**解释（范围 -128 ~ +127）。当 MOD 将敌人等级设置为 **≥ 128** 时（如150、200等），该字节被解释为负数：

| 实际等级字节值 | movsx 解释 | 经验公式中 (level+3)/3 | 效果 |
|---|---|---|---|
| 127 (0x7F) | +127 | 43.3 (正常) | 正常经验 |
| **128 (0x80)** | **-128** | **-41.7** | **经验变负** |
| 150 (0x96) | -106 | -34.3 | 大量负经验 |
| 200 (0xC8) | -56 | -17.7 | 负经验 |
| 255 (0xFF) | -1 | 0.67 | 接近零 |

### 触发过程

1. **MOD 设置敌人等级 ≥ 128**: 关卡数据 `byte_953830` 存储敌人等级为原始 byte (0-255)
2. **战斗初始化原样复制**: 在 `sub_4307CC` 第226行 `*v15 = *v9` 直接复制到 `byte_9DF781`
3. **攻击时 movsx 符号扩展**: 等级 ≥ 128 被解释为负数
4. **经验公式产出负值**: `2 × damage × (negative_level + 3) / 3` = 负数
5. **累积到经验池**: `dword_9D6F14 += 负数` → 经验池变负
6. **战后分配无下界检查**: `sub_43B7FC` 第114行仅检查 `> 30000`，**完全没有 `< 0` 的保护**
7. **存入角色数据**: 负经验被写入 `current_exp` (int16)，显示为负数

### 数值实例

MOD 设敌人等级 = 200 (实际被解释为 -56)，角色造成 500 伤害，未击杀：
```
经验 = 2 × 500 × (-56 × 500 / 3 + 500) / ... 
     = 2 × ((-56 × 500)/3 + 500)
     = 2 × (-9333 + 500)
     = 2 × (-8833) = -17666
```
每次攻击命中，经验池**减少 17666**。

---

### 次要原因：exp_bonus 乘法的 int32 溢出

即使敌人等级 < 128（保持正数），当以下条件同时满足时，战后分配阶段也可能产生负经验：

**条件组合**:
- 大量高等级(如 Lv100~127)、高 HP 敌人被击杀
- 角色拥有较高的 `exp_bonus`（鬼才 ≥ 120%）

**溢出路径** — `sub_43B7FC` 第103-104行:
```c
*v19 += (v18[31] * *v19 + 99) / 100;
```

当 `v18[31]`（exp_bonus, int16）× `*v19`（累积经验, int32）超过 INT32_MAX (2,147,483,647) 时，乘积**溢出翻转为负数**。

**数学验证** (exp_bonus=150%, 累积经验=15,000,000):
```
150 × 15,000,000 = 2,250,000,000 > INT32_MAX
溢出后: 2,250,000,000 - 4,294,967,296 = -2,044,967,296
bonus = (-2,044,967,296 + 99) / 100 = -20,449,672
最终经验 = 15,000,000 + (-20,449,672) = -5,449,672 (负数!)
```

此场景需要 **经验池累积达到千万级**，对应战斗条件为：约25~30个 Lv100+ HP15000+ 敌人被全灭。在后期高难度 MOD 中完全可能出现。

---

### 为什么原版游戏不会触发

1. 原版敌人最高等级约 57~60，远低于 128 阈值
2. 原版 HP 上限和等级组合下，经验累积不会达到 int32 溢出阈值
3. 原版 exp_bonus 值较低(通常 10~50%)

### 根本修复方向

| 问题 | 修复方式 |
|------|---------|
| 等级 ≥ 128 符号问题 | 经验计算时改用 `movzx`（无符号扩展）替代 `movsx` |
| 乘法溢出 | 在 `exp_bonus × *v19` 前先做上限截断，或使用 64 位中间变量 |
| 缺少下界保护 | 在 `*v19 > 30000` 检查后增加 `if (*v19 < 0) *v19 = 0` |
