## 2. 阴影渲染路径：sub_406864

### 2.1 代码位置

`decompile/406864.c:37-38`（标准渲染分支）：

```c
if ( (dword_754810 == 200 || dword_754810 == 20)
    && *(int *)(dword_75480C + 220) > 0 )
    sub_458020(
        dword_755AF0,                           // Cha.JVG 句柄
        dword_7547FC,                           // 实体屏幕 X
        dword_754800,                           // 实体屏幕 Y
        *(_WORD *)(dword_75480C + 220),         // 阴影帧 = d55
        a1, 0, 0, -1);
```

行 72-78 为带变换的渲染分支，逻辑相同，调用 `sub_45AA08` 替代 `sub_458020`。

### 2.2 渲染顺序

```
sub_406864 循环体内:
  1. if (type==200 || type==20) && d55 > 0 → 绘阴影 (sub_458020)
  2. switch(d24) → 绘主精灵
```

阴影在主精灵之前渲染，因此永远显示在角色**下方**。

## 3. d55：持久字段 + SetShadow 事件双来源

### 3.1 持久字段：存储在 TKMat.dat

**实测数据**（`逆向工作区/dat_decoder/TKMat.Dat`）：

| Entity | d55 | 阴影效果 |
|--------|-----|---------|
| #4005 | 0 | 无阴影 |
| #4006 | 1 | 小阴影 (39×23) |
| #4007 | 1 | 小阴影 (39×23) |

d55 直接存储在 TKMat.dat 的 384 字节实体记录中（字节偏移 220），与 type、scene_id 等字段一样是**持久数据**，不是运行时计算值。

### 3.2 运行时覆盖：SetShadow 事件

`decompile/40C428.c` — `sub_40C428`（addr `0x40C428`）：

```c
int __cdecl sub_40C428(__int16 entity_id, __int16 shadow_frame)
{
    v3 = &dword_51AF40[96 * entity_id];
    if ( *v3 != 200 && *v3 != 20 )
        return error;
    v3[55] = shadow_frame;   // ★ 运行时写入 d55
    return shadow_frame;
}
```

事件脚本执行器的 case 22（`decompile/40EBD4.c:231`）调用 SetShadow，**运行时覆盖** d55 值。

### 3.3 双来源总结

| 来源 | 何时 | 说明 |
|------|------|------|
| TKMat.dat 持久字段 | 文件加载时 | 初始值，如 #4006 d55=1 |
| SetShadow 事件脚本 | 游戏运行时 | 可能覆盖持久值为其他值 |

编辑器不运行脚本，直接读取 TKMat.dat 中的 d55 持久值即可。

## 4. 阴影混合模式：硬编码减法 sub_45871C

### 4.1 调用链

```
sub_406864:38
  → sub_458020(Cha.JVG, X, Y, d55, buffer, 0, 0, -1)
                                    a6=0  a7=0
    → a6==a7==0 → sub_45871C  (或 sub_458130 在 16-bit 模式下)
```

**阴影始终走 sub_458020(a6=0, a7=0)，路径固定，无配置参数。**

### 4.2 逐通道减法算法

`decompile/45871C.c:118-134` — RGB565 像素逐通道减法钳 0：

```
dst.R' = max(dst.R − src.R, 0)
dst.G' = max(dst.G − src.G, 0)
dst.B' = max(dst.B − src.B, 0)
```

### 4.3 阴影精灵颜色在减法下的效果

| 精灵像素 | 算法 | 视觉 |
|---------|------|------|
| RGB(~8, ~12, ~8) 接近黑 | dst−8 ≈ dst | 几乎透明 |
| RGB(~82, ~81, ~82) 中灰 | dst−82 | 中等压暗 |
| RGB(~156,~154,~156) 亮灰 | dst−156 | 显著压暗 → **阴影最深处** |

灰色渐变椭圆 + 减法混合 = 自然的脚底阴影效果。

### 4.4 编辑器 PIL 实现

```python
# _pil_subtract — ImageChops.subtract = max(dst-src, 0)
blended = ImageChops.subtract(dst_crop, masked)
composite.paste(blended, (dx, dy))
```

## 5. 主精灵混合模式：d24/d25 控制

`sub_406864:39-69` — 按实体记录 d24（字节偏移 96）走 switch：

| d24 | 函数 | 混合效果 | 参数 d25 |
|-----|------|---------|---------|
| 0 | sub_4544EC | 正常贴图 | — |
| 1 | sub_454D24 | 染色 | d25 为 5-bit RGB 颜色 |
| 2 | sub_4559D0 | **加法发光** | 0或>31→全加法; 1~31→缩放加法 |
| 3 | sub_458020→45871C | **减法压暗**（同阴影） | — |
| 4 | sub_459168→459854 | 亮度 alpha 融合 | — |
| 5 | sub_458D08 | 水平翻转 | — |

### 5.1 编辑器 PIL 实现

| 模式 | PIL 实现 | 核心操作 |
|------|---------|---------|
| 0 正常 | `_pil_normal` | `composite.paste(rgba, (dx, dy), rgba)` |
| 1 染色 | `_pil_tint` | `R*=r/31, G*=g/31, B*=b/31` 按 d25 分量 |
| 2 加法 | `_pil_additive` | `ImageChops.add(dst, src×param/32)` |
| 3 减法 | `_pil_subtract` | `ImageChops.subtract(dst, src)` |
| 4 亮度α | `_pil_luma_alpha` | NTSC luma 5-bit → Image.composite(src, dst, mask) |
| 5 翻转 | `ImageOps.mirror` | 水平镜像 + 正常合成 |

## 7. 编辑器中阴影字段的使用

### 7.1 字段定义

`mat_editor.py` BASIC_FIELDS 中：

```python
("shadow_frame", 55, "阴影帧",
 "sub_406864:37 — Cha.JVG全局帧索引。0=无阴影, 1=小阴影(39×23), 2=大阴影(65×33)")
```

### 7.2 UI 呈现

- 显示在右侧"基础属性"组，Combobox 下拉：
  - `0-无阴影`
  - `1-小阴影(39×23)`
  - `2-大阴影(65×33)`
- `_show_record` 设置 Combobox 为 `"{val}-{label}"` 格式
- `_read_form` 通过 `split('-')[0]` 自动解析为整数

### 7.3 渲染逻辑

`_vis_render_scene` 中：

```python
# sub_406864:37 — d55>0 时以该值为 Cha.JVG 全局帧索引绘阴影
shadow_fi = r.get('d55', 0)
if shadow_fi > 0 and (tval == 200 or tval == 20) and jvg is self._cha_jvg:
    shadow_rgba = _get_jvg_frame_rgba(jvg, 0, shadow_fi)
    # ... 取帧偏移 ...
_pil_subtract(composite, shadow_rgba, shadow_sx, shadow_sy)  # 减法混合
```

### 7.4 渲染架构

地图预览使用 **PIL 预合成**方案：

1. 背景：SC.GRP → PIL RGB Image
2. 实体按 Y 坐标升序排列
3. 对每个实体：
   - 阴影 → `_pil_subtract`（模式 3 减法）
   - 主精灵 → 按 d24 选择 `_pil_normal/additive/subtract/luma_alpha`
   - 标签 → PIL ImageDraw.text
4. PIL Image → ImageTk.PhotoImage → Canvas 显示
5. 选中高亮：PIL 矩形叠加 + `_vis_hit_regions` 矩形命中
