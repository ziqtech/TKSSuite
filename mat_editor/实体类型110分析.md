# 实体类型 110 — 可拾取物品（地图散落道具/宝箱）

> 逆向依据: `运行时转储/decompile/408B30.c`, `408E5C.c`, `405CBC.c`, `4128AC.c`, `40CE30.c`, `452AC0.c`

## 一、真实含义

**type=110 是地图上的可拾取物品实体**，玩家点击后获得随机道具。编辑器中命名为"特殊机关"，更准确的含义是**可拾取的散落物品/宝箱**。

---

## 二、触发入口链

```
玩家点击 → sub_408E5C (玩家交互处理)
         → 碰撞检测 sub_40818C / sub_4099B0
         → 脚本执行 (如果 d34>0, 先执行B链脚本)
         → sub_408B30 (type=110 专用拾取逻辑)
```

关键代码 `sub_408E5C.c:75`:
```c
if ( dword_755254 == 110 )          // 如果实体类型是 110
    sub_408B30(dword_75524C, dword_755250);  // 调用拾取处理
```

特殊地，type=110 **无需 d34(B链脚本) 非零即可点击**，是唯一不需要脚本链就可交互的实体类型（`sub_408E5C.c:46`）:
```c
// 其他类型需要 *(_DWORD *)(entity + 136) != 0 (即 d34>0) 才可交互
// type=110 短路跳过此检查
if ( (flags & 1) == 0 || type != 110 && !*(_DWORD *)(entity + 136) )
    goto LABEL_52;  // 不可交互
```

## 四、sub_408B30 完整逻辑（逐行逆向标注）

### ① 已拾取检查

```c
// byte+9 是 flags DWORD 的第二字节, bit0 = flags 的 bit8 (已拾取)
if ( (*(_BYTE *)(a2 + 9) & 1) != 0 )
    return sub_40B1B4(11, 18, 30, 1, 0, 1);  // 播放"无法拾取"音效并返回
```

已被拾取过的物品再次点击只播放音效，不给道具。

### ② 三组物品随机生成

```c
// 组1: d[53]~d[56]
if ( *(_DWORD *)(a2 + 212) )  // 如果组1物品ID != 0
{
    // 物品ID: 若 min>=max 则固定取 min, 否则随机 [min, max]
    v11 = d53 + random(d54 - d53 + 1);
    // 数量: 若 min>=max 则固定取 min, 否则随机 [min, max]
    v8  = d55 + random(d56 - d55 + 1);
}

// 组2: d[57]~d[60]  — 同理, d57!=0 时生成
// 组3: d[61]~d[64]  — 同理, d61!=0 时生成
```

随机函数 `sub_452AC0(range)` 返回 `[0, range)` 的均匀分布值。

### ③ 给予物品（调用 sub_40CE30 = GetItem）

```c
sub_40CE30(item_id, qty, 1);   // 参数: 道具ID, 数量, 1=显示提示
```

| item_id | 行为 |
|---------|------|
| 10000   | 金钱, 上限30000 |
| 其他    | 普通道具, 单格上限99, 已有则累加, 新道具分配背包槽 |

三组物品依次给予，每组独立判断（item_id 和 qty 都非零才给予）。

### ④ 行为模式分支（d[52]）

```c
v3 = *(_DWORD *)(a2 + 208);    // d52 = behavior_mode

if ( v3 == 0 )     // 模式0: 标记已拾取 + 播放拾取动画
{
    flags |= 0x100;              // 设置 bit8 (已拾取)
    if ( d50 != 0 )              // 如果帧计数器>0
    {
        if ( d64 <= ++d68 )      // 递增当前帧, 到达最大帧则停在最大
            d68 = d64 - 1;
        d56 = d68 + d51;         // 新帧 = 当前帧 + 基偏移 (播放拾取动画)
    }
}
else if ( v3 == 1 )  // 模式1: 完全移除实体
{
    flags &= ~1;     // 清除 bit0 (禁用)
    flags &= ~2;     // 清除 bit1 (隐藏)
    // 实体从此不可见不可交互
}
// v3 >= 2: 无行为 (什么都不做, 可重复拾取)
```

## 五、渲染逻辑（sub_405CBC.c:132）

```c
if ( v11 == 110 )
{
    if ( v1 )   // 如果动画集(JVG)存在
    {
        v2[51] = sub_45410C(v1, v2[50], 0);  // 获取精灵句柄
        v2[14] = v2[17] + v2[51];             // 帧索引 = 基础帧 + 帧偏移
    }
}
sub_406E50(v2);  // 统一渲染入口
```

type=110 使用 `anim_set[9]` 指定的 JVG 文件，`d[50]` 为精灵块索引，`d[51]` 为运行时句柄，帧索引 = `d[17]`(基础帧) + `d[51]`(偏移)。

用于拾取特定 type=110 物品时触发的过场剧情（如获得重要道具时的特殊演出）。

## 七、完整行为流程图

```
玩家点击 type=110 实体
    │
    ├─ 检查: flags bit8 已拾取?
    │   ├─ 是 → 播放"无法拾取"音效, 结束
    │   └─ 否 ↓
    │
    ├─ 检查: 有B链脚本? (d34>0)
    │   └─ 是 → 执行脚本 (sub_40EBD4)
    │
    ├─ 组1: d53!=0?
    │   └─ 是 → item=random(d53,d54), qty=random(d55,d56) → GetItem
    ├─ 组2: d57!=0?
    │   └─ 是 → item=random(d57,d58), qty=random(d59,d60) → GetItem
    ├─ 组3: d61!=0?
    │   └─ 是 → item=random(d61,d62), qty=random(d63,d64) → GetItem
    │
    ├─ behavior_mode (d52):
    │   ├─ 0: flags|=0x100 (标记已拾取), 播放拾取动画
    │   ├─ 1: flags&=~3 (禁用+隐藏, 实体消失)
    │   └─ ≥2: 无操作 (可重复拾取)
    │
    └─ 完成
```

## 八、与 mat_editor.py 的对应关系

`mat_editor.py` 中的字段注释和 `_TYPE_LABELS[110]` 映射与反编译源码**完全一致**：
