# 敌方属性加成倍率（enemy_power）字段分析

## 基本信息

- **文件偏移**: WarData.dat 每条记录 [88-105]，共 18 字节（对应 18 个敌军槽位）
- **内部变量**: `byte_953830`
- **编辑器当前命名**: "属性加成倍率"（原"AI编组"，已修正）
- **War.dll 官方编辑器标签**: "人物归属"
- **运行时结构体**: WarPC 格式，527 × int16（与 WarPC.dat 解压后结构一致，sub_432668 验证）

**关键**: `!*v9` 条件确保只有 `enemy_power == 0` 的普通士兵才会作为增援出场。非零值的敌人是固定出场的将领/Boss。

### sub_4302D8（属性计算，地址 0x4302D8）— 决定性证据

```c
int __cdecl sub_4302D8(_WORD *a1, unsigned __int8 level, unsigned __int8 grp)
```

`a1` 是 WarPC 格式的角色结构体（527 × int16，sub_432668 验证布局一致）。

#### 参数映射（与 WarPC 结构体交叉验证）

| a1索引 | WarPC字段 | 语义 | grp加成公式 | 除数 |
|--------|-----------|------|-------------|------|
| a1[7] | hp_base | 生命基础 | `+ grp × a1[7]` | 1 (×100%) |
| a1[9] | mp_base | 内力基础 | `+ grp × a1[9] / 4` | 4 (×25%) |
| a1[11] | atk_base | 攻击基础 | `+ grp × a1[11] / 8` | 8 (×12.5%) |
| a1[13] | def_base | 防御基础 | `+ grp × a1[13] / 8` | 8 (×12.5%) |
| a1[15] | hit_base | 命中基础 | `+ grp × a1[15] / 12` | 12 (×8.3%) |
| a1[17] | eva_base | 闪避基础 | `+ grp × a1[17] / 12` | 12 (×8.3%) |
| a1[19] | spd_base | 速度基础 | `+ grp × level / 10` | (等级相关) |

#### 完整反编译代码（关键部分）

```c
// ===== 等级基础成长（每级循环）=====
for ( i = 1; level > i; ++i )
{
    // 成长率按等级分三档（来自 a1[264]/[265]/[266]）
    if ( i >= 21 )
    {
        if ( i >= 41 )
            v4 = (__int16)a1[266];  // 41级以上成长率
        else
            v4 = (__int16)a1[265];  // 21-40级成长率
    }
    else
    {
        v4 = (__int16)a1[264];      // 1-20级成长率
    }
    // 六个属性基础值按成长率递增
    a1[7]  += (__int16)a1[7]  / v4 + 1;  // 生命
    a1[9]  += (__int16)a1[9]  / v4 + 1;  // 内力
    a1[11] += (__int16)a1[11] / v4 + 1;  // 攻击
    a1[13] += (__int16)a1[13] / v4 + 1;  // 防御
    a1[15] += (__int16)a1[15] / v4 + 1;  // 命中
    a1[17] += (__int16)a1[17] / v4 + 1;  // 闪避
    ++a1[19];                             // 速度（每级+1）
}

// ===== enemy_power 属性加成 =====
if ( grp )
{
    a1[7]  += grp * a1[7];              // 生命: +grp×100%
    a1[9]  += grp * (__int16)a1[9] / 4; // 内力: +grp×25%
    a1[11] += grp * (__int16)a1[11] / 8; // 攻击: +grp×12.5%
    a1[13] += grp * (__int16)a1[13] / 8; // 防御: +grp×12.5%
    a1[15] += grp * (__int16)a1[15] / 12; // 命中: +grp×8.3%
    a1[17] += grp * (__int16)a1[17] / 12; // 闪避: +grp×8.3%
    a1[19] += grp * level / 10;          // 速度: +grp×level/10
}

// 上限
if ( (__int16)a1[7] > 20000 )  a1[7] = 20000;   // 生命上限
if ( (__int16)a1[9] > 20000 )  a1[9] = 20000;   // 内力上限

a1[2] = level;                        // 设置等级
a1[4] = 8 * level * level + 92;       // 设置升级经验
```

#### 不在加成范围内的属性

WarPC 的 8 属性中，以下三个**不受 enemy_power 影响**：

| a1索引 | WarPC字段 | 语义 | 原因 |
|--------|-----------|------|------|
| a1[21] | luk_base | 幸运 | 非直接战斗属性，不随阶级放大 |
| a1[23] | mov_base | 移动 | 移动力固定，不受阶级影响 |
| a1[25] | wis_base | 悟性 | 学习相关属性，非战斗属性 |

## 属性加成效果表

| grp 值 | 生命 +% | 内力 +% | 攻击/防御 +% | 命中/闪避 +% | 速度 |
|--------|---------|---------|-------------|-------------|------|
| 0 | +0% | +0% | +0% | +0% | +0 (可增援) |
| 1 | +100% | +25% | +12.5% | +8.3% | +level/10 |
| 2 | +200% | +50% | +25% | +16.7% | +2×level/10 |
| 3 | +300% | +75% | +37.5% | +25% | +3×level/10 |

> 注1: 基础属性先经等级成长计算，再叠加 grp 加成。生命/内力上限 20000。
> 注2: 速度为绝对值加成（`grp × level / 10`），而非百分比。

## 实战示例：WarData 序号2 中的「僕役」

### 战场配置

WarData.dat 战斗序号2（偏移 996）中，同一个角色「僕役」（WarPC[115]，enemy_id=80）以不同阶级出场：

| 槽位 | 角色 | enemy_power | LvP1 | LvP2 | 语义 |
|------|------|-------------|------|------|------|
| slot 1 | 僕役 | **3** | 1 | 3 | 将领/Boss（出场即获得 3 级属性加成） |
| slot 2-4 | 僕役 | **0** | 2 | 3 | 普通士兵（3 名，可被选为增援） |

> 注: enemy_id=80 经 `+35` 偏移后对应 WarPC[115]。LvP1/LvP2 决定等级在队伍平均等级的浮动范围。

### 僕役基础属性（WarPC[115]，level=1）

| 生命 | 内力 | 攻击 | 防御 | 命中 | 闪避 | 速度 | 成长率(Lv1-20) |
|------|------|------|------|------|------|------|---------------|
| 15 | 10 | 15 | 10 | 15 | 15 | 24 | 27 |

### 计算过程（以等级 10 为例）— 反编译证据追踪

以下按反编译代码精确再现（整数算术），调用链：

```
sub_4307CC:225  qmemcpy(v7, WarPC[115], 1054)  // 复制僕役 Lv1 原始数据
sub_4307CC:227  sub_430578(v7, enemy_power=3, LvP1=1, LvP2=3, avg_lv)
sub_430578:42   sub_4302D8(v7, computed_level=10, enemy_power=3)
```

`sub_4302D8` 接收的是刚从 WarPC 复制的 **Lv1 原始属性**（`qmemcpy` 复制时 level 字段为 1），然后执行两阶段计算：

**Phase 1: 等级成长** — `sub_4302D8:32-51`

```c
// 证据: sub_4302D8:32-51 循环体
for ( i = 1; level > i; ++i )     // 循环 level-1 = 9 次
{
    if ( i >= 21 ) { v4 = a1[266]; }
    else { v4 = a1[264]; }         // 僕役 a1[264]=27 (growth_1_20)
    a1[7]  += a1[7]  / v4 + 1;    // hp_base  每级 +stat/27 + 1
    a1[9]  += a1[9]  / v4 + 1;    // mp_base
    a1[11] += a1[11] / v4 + 1;    // atk_base
    a1[13] += a1[13] / v4 + 1;    // def_base
    a1[15] += a1[15] / v4 + 1;    // hit_base
    a1[17] += a1[17] / v4 + 1;    // eva_base
    ++a1[19];                      // spd_base 每级 +1
}
// 关键: 每次迭代使用上一轮更新后的值 (a1[7] += a1[7]/v4 + 1)
// 僕役 hp=15 < v4=27, 整数除法 15/27=0, 16/27=0, ..., 23/27=0 全程截断为0
// 因此每级增量 = 0 + 1 = 1, 9 次迭代共 +9

// 对比: 高属性角色 (WarPC[69] hp_base=300, growth=27)
// Lv1→2: hp += 300/27+1 = 11+1 = 12 → hp=312 (不是 +1 !)
// Lv3→4: hp += 324/27+1 = 12+1 = 13 → hp=337 (增量逐级增大)
// 同一公式, 属性高低导致成长差异巨大

// 僕役 Lv1→Lv10 逐级 hp 追踪 (每轮用上一轮新值):
// i=1: hp=15 + 15/27+1=15+1=16
// i=2: hp=16 + 16/27+1=16+1=17
// ...
// i=9: hp=23 + 23/27+1=23+1=24

**Phase 2: enemy_power 加成** — `sub_4302D8:53-62`

```c
// 证据: sub_4302D8:53-62
if ( grp ) {
    a1[7]  += grp * a1[7];              // sub_4302D8:55
    a1[9]  += grp * a1[9] / 4;          // sub_4302D8:56
    a1[11] += grp * a1[11] / 8;         // sub_4302D8:57
    a1[13] += grp * a1[13] / 8;         // sub_4302D8:58
    a1[15] += grp * a1[15] / 12;        // sub_4302D8:59
    a1[17] += grp * a1[17] / 12;        // sub_4302D8:60
    a1[19] += grp * level / 10;         // sub_4302D8:62
}
```

## 字段语义总结

| 项目 | 说明 |
|------|------|
| **实际功能** | 敌方角色属性加成倍率（阶级系数） |
| **值为 0** | 普通士兵 — 可被选为增援，无属性加成 |
| **值为 1+** | 将领/Boss — 固定出场不可增援，获得对应倍率属性加成 |
| **与 AI 的关系** | 无任何关系 |
| **War.dll 官方命名** | "人物归属"（指角色身份阶级） |
| **受影响的属性** | 生命、内力、攻击、防御、命中、闪避、速度（6战斗属性+1等级属性） |
| **不受影响的属性** | 幸运、移动、悟性 |
