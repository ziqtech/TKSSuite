# 战场预置陷阱系统 — 完整逆向分析

> 基于 `运行时转储` 反编译代码 + WarData.dat/WarWay.dat/TKKon.dat 数据交叉验证
>
> 最后更新: 2026-05-25

## 概述

游戏战斗场景中存在两类陷阱：

| 特性 | 预置地图陷阱 | 玩家部署陷阱 |
|------|------------|------------|
| 数据来源 | **WarData.dat** (498字节/场景) | 技能系统 (sub_4458B0) |
| 陷阱类型 | WarData 预定义 (类型值 1-6) | 技能槽位 - 3 (1-5, 山崩\~滾木) |
| 陷阱威力 | **随机** `[min, max]` 范围 | `(角色等级 + 4) / 5` |
| 每场景数量 | 最多 28 个 | 每陷阱技能 1 个 |
| 触发函数 | sub_434C0C | 同左 |

## 8. 关键结论

1. **存在地图预置陷阱**: 数据来自 WarData.dat 的 28 个陷阱槽位，类型定死、威力随机
